# 케어브릿지 기획 확정안 v0.3 (제안)

2026-10-15 · 근거는 각 문장 끝 각주와 맨 아래 [참고 자료](#참고-자료)에 있습니다. 주요 자료: [10/15 멘토링 회의록](../../회의록/2026-10-15-멘토링.md), [최소구조설계 v0.1](../설계/최소구조설계-v0.1.md), 10/12 공모전 답변서 요약(레포 밖 공유 자료), [(기획 담당) PM용 기획서](../기획/기획초안/기획 담당-PM용기획서.md)

> **상태: 팀 결정 전 제안.** 각 항목의 "제안"은 Claude의 추천이고, 팀이 ✅/✏️ 로 표시해 확정하면 이 문서가 v0.3 기준이 됩니다.

## 확정 방법 (한 줄)

**아래 결정 10개만 이번 주 안에 팀 회의 한 번으로 못 박고, 나머지는 개발하면서 정한다.** 10/22 멘토링 화면 시연에 필요한 것부터 순서대로 놓았습니다. 1~6이 정해지면 바로 개발에 들어갈 수 있습니다.

새 기획의 출발점은 교육용 v0.2가 아니라 **현장용 v0.1**입니다. v0.1에 "병기 + 듣기/말하기"를 더하고 관리자 흐름은 핵심(M3·M4·M6)만 남기면 v0.3이 됩니다. v0.2(교육생·강사 구조)는 보관만 합니다.

## 결정표

| # | 정할 것 | 제안 | 이유 |
|---|---|---|---|
| 1 | **한 줄 정의** | 외국인 돌봄 인력이 **모국어 AI 버디와 대화하면 한국어 돌봄 기록이 완성되고, 그 과정에서 한국어를 계속 보고 듣게 되는** 앱. 도입은 **교육기관 먼저**, 이후 요양시설. | 멘토 결론 그대로. "교육용 앱"이 아니라 "우리 앱을 교육기관이 먼저 쓴다".[^m-dir] |
| 2 | **주 사용자** | 외국인 **요양보호사 + 돌봄 보조 인력**(식사·위생 등 직접 돌봄). 언어는 MVP **베트남어 1개**. | 멘토의 시설 사례.[^m-target] 공모전 원안 문구도 "외국인 요양보호사 후보 **및 돌봄인력**"이라 원안과 더 가까워짐.[^origin] 언어는 (기획 담당) PM용 기획서 범위 유지[^v1], 중국어는 확장 슬라이드로. |
| 3 | **관리자(담당자) 화면** | **MVP에 포함하되, 개발 시간이 부족하면 뺀다.** 포함 범위는 v0.1의 M3 승인 대기 목록 → M4 기록 검토(한국어 기록지 + 항목별 원문 근거) → M6 승인. 시간이 부족하면 승인 흐름을 빼고 **M4를 읽기 전용 결과 화면 1장**으로만 남긴다. | 팀 결정(10/15): "개발 시간 부족 시" 단서.[^team-admin] 멘토는 "과감히 빼도 된다"고 했지만,[^m-mvp] 원안이 "돌봄인력 **담당자의 의사결정 보조**"이고 후보작 구현 가점이 걸려 있음.[^origin] 또 멘토가 말한 "기관은 기록을 받고 싶어 한다"를 한 화면으로 보여 줄 수 있음.[^m-target] |
| 4 | **기준 서식과 항목** | **시설급여 제공기록지(별지 제16호, 교재 p.332~333)**[^textbook] 1종. 항목은 v0.1의 12개(매일 필수 / 조건부 / 선택) 그대로.[^v01-items] | 멘토 "공개된 표준 서식으로만", 교재 9장.[^m-data] 멘토가 든 보조 인력 사례가 모두 요양시설.[^m-target] E-7 근무처 요건도 노인의료복지시설(추론).[^e7] 항목 매핑이 v0.1에 이미 끝나 있음. 재가·주야간은 "서식만 바꾸면 된다"는 확장성으로 발표. |
| 5 | **병기 규칙** | ① AI 메시지는 항상 **한국어 + 모국어** 두 줄. ② 사용자가 모국어로 답하면 바로 아래에 **"한국어로는: …"** 를 붙여 보여 준다. ③ 한국어 줄마다 **🔊 듣기**. ④ 요양 용어는 밑줄 → 누르면 **용어 카드**(뜻·발음·교재 쪽수). ⑤ 설정에서 **모국어 우선 ↔ 한국어 우선** 전환. | 멘토의 핵심 추가 요구("노출이 제일 중요", 점차 한국어로).[^m-bilingual] 한국어 학습 앱처럼 보이지 않도록 퀴즈·점수는 넣지 않음. |
| 6 | **음성** | **STT: 마이크를 누를 때만 받아쓰기**, 음성 파일은 저장하지 않고 텍스트만 남김. **TTS: 한국어 듣기 버튼.** | 멘토 "둘 다".[^m-voice] 10/12 답변서에서 "상시 녹음 대신 선택적 입력"이라고 이미 답했으므로 그 약속과도 맞음.[^qa] |
| 7 | **AI가 하는 일 / 안 하는 일** | 한다: 대화에서 나온 사실을 서식 칸에 나눔, 빠진 필수 항목 되묻기, 모호한 표현 구체화("조금" → 1/2 미만?), 용어 설명, 상태 급변 시 "선생님께 바로 알리세요" 안내. 안 한다: 말하지 않은 내용 추정, 진단·복약 지도, 공단 자동 전송. **용어 설명은 표준교재·용어집에 있는 것만**, 없으면 "교재에 없는 내용이에요"라고 답. | 멘토 "할루시네이션 나면 망한다".[^m-data] 10/12 답변서의 "AI가 안 하는 것"과 동일하게 유지.[^qa] 의료행위 금지는 교재 p.77.[^textbook] |
| 8 | **되묻기 종료 기준** (미결 → 제안) | **횟수가 아니라 필수 항목이 다 확인되면 종료.** 각 항목은 `없었어요` `모르겠어요`로도 확인된 것으로 친다. 같은 항목은 **최대 2번**까지만 묻고, 그래도 안 되면 "확인 필요"로 남겨 결과 화면에 표시. | 멘토 가이드의 "필수 정보 확인 여부로 종료" 원칙[^prep] + 사용자를 몰아붙이지 않는 안전장치. 10/15 멘토링에서는 미결.[^m-open] |
| 9 | **정서 대화** (미결 → 제안) | 별도 기능으로는 **넣지 않는다.** 톤으로만: 공감 한마디 → 질문, 마지막에 "오늘도 수고했어요". | 교육원장 인터뷰에서 필요성이 안 나왔고,[^prep] MVP를 줄이라는 멘토 조언.[^m-mvp] "다독이는 버디" 콘셉트는 유지됨. |
| 10 | **교육 단계 기능**(낱말 맞추기, 진도 체크, 실습일지)[^m-edu] | **MVP 제외, 발표의 로드맵 슬라이드**로만. MVP 안에서는 5-⑤ "한국어 우선 전환"이 단계적 학습을 대신 보여 줌. | 공모전 접수까지 2주. 화면 수를 늘리지 않고 "점차 한국어로"를 보여 줄 수 있음. |

## 확정 후 MVP 화면 (10/22 시연 목표)

v0.1 화면 ID를 그대로 씁니다.

| 순서 | 화면 | v0.1 대비 바뀌는 점 |
|---|---|---|
| 1 | B2 오늘 담당 어르신 목록 | 그대로 (로그인 B1은 데모 계정으로 생략) |
| 2 | B3 채팅 | **병기 2줄, 🔊, 🎤, 용어 카드** 추가 |
| 3 | B4 되묻기 | 빠른 답 칩도 병기. 종료 기준은 결정 8 |
| 4 | B5 마무리 요약 확인 | 요약 카드를 **한국어 기록 문장 + 모국어 설명** 병기로 |
| 5 | M3 → M4 → M6 관리자 검토·승인 (데스크탑) | 결정 3. 개발 시간이 부족하면 M4 읽기 전용 결과 화면 1장으로 대체 |

빼는 것: B1, B6, M1·M2·M5, 보호사 컨디션 알림, 기관 시스템 전송.

### 시연 시나리오 3개

멘토가 권한 "주고받는 대화 형태" 시연입니다.[^m-demo]

1. **기본:** v0.1 2-3 대화 예시(응옥린, 305호)를 병기로 바꿔서, 모국어로 말해도 한국어가 한 번씩 보이고 들리는 장면.
2. **모호한 답:** "조금 드셨어요" → AI가 "반보다 적었어요?"로 구체화 → 서식에 "1/2 미만".
3. **보고 필요:** "어르신이 넘어지셨어요" → 기록은 이어가되 "선생님께 바로 알리세요" 안내 카드.[^v01-report]

## 10/12 공모전 답변서와 맞는지

답변서는 우리가 주최 측에 이미 한 약속이라 어긋나면 안 됩니다.[^qa] 확인해 보니 새 방향과 충돌하는 곳은 없고, **표현만 맞추면** 됩니다.

| 답변서에서 한 말 | v0.3에서의 표현 |
|---|---|
| 한국어 기록지원이 중심, 번역은 선택 | 결과물은 한국어 기록. 모국어는 이해를 돕는 병기. |
| 상시 녹음 대신 선택적 메모 | 누를 때만 받아쓰기, 음성 파일 저장 안 함 (결정 6) |
| 대상: 교육기관(강사·교육생), 요양기관 검토자 | 교육기관에서 먼저 적용 → 요양시설로 확장. 검토자는 관리자 화면(결정 3) |
| AI가 안 하는 것 (추정, 진단, 공단 입력 등) | 결정 7과 동일 |
| 합성 사례로 수기 vs 초안 보조 비교 | 그대로 유지 (평가 계획) |
