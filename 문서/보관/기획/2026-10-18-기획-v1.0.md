## v0.5 → v1.0에서 바뀐 점

- **기록 항목 8개 → 9개.** 9번째로 **‘인지 변화’**(기억·날짜·사람 헷갈림, 호전/유지/악화)를 넣었습니다. 기분은 따로 두지 않습니다.[3]
- **표현 도우미 W6(도우미)와 승인본 인쇄·PDF를 MVP에 넣었습니다.** 작성자 하단 탭은 4개로 고정입니다.[3]
- **특이사항 200자는 막지 않고 경고만** 합니다. 글자 수를 보여 주고, 넘으면 경고를 띄웁니다.[3]
- **녹음 시작·끝은 작성자가 버튼으로 직접** 누릅니다. 자동 정지는 없습니다.[4]
- **교육 연습은 ‘교육용 기관’ 계정으로 완전히 분리**합니다. 켜고 끄는 교육 모드는 없습니다.[5]
- **기기는 사용자별로 유연하게** 씁니다. 모든 화면이 휴대폰과 PC에서 다 열립니다.[6]
- **UX 원칙 추가:** 글은 적게, 아이콘으로 직관적으로, 나라·문화 차이로 헷갈리지 않게.[7]
- **기술 스택 확정:** Next.js(TypeScript) 반응형 웹앱, Supabase, Vercel, 서버 음성 인식, Claude API.[8]
- **교재 텍스트는 그대로 사용**합니다(공개 자료). 이미지는 확인이 필요하지만 사용 가능하다고 가정합니다.[3]
- **베트남어 검수자는 없습니다.** 번역과 화면 문구는 팀이 자체 검증합니다.[3]

## 한 줄 정의

**외국인 요양보호사가 음성 메모 하나로 한국어 기록 초안을 만들고, 담당자가 검토·승인하는 서비스.**[9] 화면은 한국어가 위, 모국어가 아래이고, 최종 기록은 항상 한국어입니다.[9]

## 기능과 MVP

MVP는 **"음성 메모 → 9개 항목 초안 → 빈 칸 채우기 → 담당자 승인 → 인쇄·PDF"** 한 바퀴를 시설과 재가 모두에서 끝까지 돌리는 것입니다.[9][3]

**작성자 (기본 배치: 휴대폰)**

| 기능 | 우선순위 |
| --- | --- |
| 오늘의 어르신 카드 (작성 전·작성 중·검토 대기·되돌아옴·승인) | MVP |
| 음성 메모 (수동 시작·끝, 글로 쓰기 전환) | MVP |
| AI 9개 항목 정리 (상태·원문 근거) | MVP |
| 빈 칸·모호함 표시, 칸 직접 채우기 | MVP |
| 사투리·모호 표현 풀이 (짐작 뜻 + 확인 필요) | MVP |
| 한국어·모국어 병기와 듣기, 내 말 ↔ 기록 표현, 용어 뜻 보기 | MVP |
| 항목별 [맞아요] / [달라요], 임시 저장·이어 쓰기 | MVP |
| 되돌아온 기록 보기 (사유 한국어 + 번역) | MVP |
| 표현 도우미 W6(도우미) | **MVP** |
| 내 단어장, '한국어만 보기', 지난 기록 불러오기 | 여유 시 |

**담당자 (기본 배치: PC)**

| 기능 | 우선순위 |
| --- | --- |
| 검토 대기 목록 | MVP |
| 원문과 초안 나란히 (근거 문장 강조) | MVP |
| 수정·승인·되돌리기 | MVP |
| 공식 기록지 칸 안내 (제16호·제12호), 특이사항 글자 수·복사 | MVP |
| 기록 단계 이력 (원문 → AI 초안 → 직원 수정 → 승인본) | MVP |
| 승인본 인쇄·PDF ("공식 기록지 아님" 표시) | **MVP** |
| 가족 공유 (데모는 잠긴 버튼) | 여유 시 |

**만들지 않는 것:** 진단·건강 판단·투약 안내, 공식 기록지 대체와 공단 전송, 근무시간·급여 인정, 상시 녹음·실시간 통역, 승인 전 가족 발송, 일정 확인·전자태그(공식 앱 영역), 자동 녹음 정지.[9][4]

## 메뉴와 화면

화면 ID는 항상 이름과 함께 씁니다. 화면별 내용은 화면 설계 v1.0에 있습니다.[23]

- **작성자 하단 탭 4개:** 오늘 / 기록함 / 도우미 / 내 정보. 화면은 W0(사용 안내), W1(오늘), W2(음성 메모), W3(기록 초안 확인), W4(기록함), W5(내 정보), W6(도우미).
- **담당자 왼쪽 메뉴 4개:** 검토 대기 / 승인한 기록 / 어르신·작성자 / 설정. 화면은 R1(검토 대기), R2(검토 화면), R3(승인한 기록), R4(어르신·작성자, 설정).
- **흐름:** W1(오늘) → W2(음성 메모) → W3(기록 초안 확인) → [담당자에게 보내기] → R1(검토 대기) → R2(검토 화면) → 승인하면 R3(승인한 기록), 되돌리면 W4(기록함)에 ‘되돌아온 기록’ → W3(기록 초안 확인).

## 9개 항목과 공식 기록지 칸

8개는 10/12 답변서에 적은 초안 항목이고,[24] 9번째 ‘인지 변화’는 10/16에 추가했습니다.[3] 저장 위치까지 포함한 대응표는 데이터 구조 v1.0에 있습니다.[25]

| # | 항목 | 별지 제16호 (시설) | 별지 제12호 (재가) ⚠️ |
| --- | --- | --- | --- |
| 1 | 방문 시점 | 서비스 날짜·시간 | 일정관리 시작·종료·총시간 |
| 2 | 제공 지원 | 신체활동지원(세면·목욕·체위변경·이동), 배설 | 신체활동·인지활동·인지관리·정서·가사 및 일상생활 지원, 각 제공시간(분) |
| 3 | 식사 | 신체활동지원 > 식사(섭취량) | 식사 도움, 변화상태 식사기능 |
| 4 | 수면 | 특이사항 | 특이사항 |
| 5 | 불편감 표현 | 특이사항, 기능 변화 | 변화상태 신체기능, 특이사항 |
| 6 | 복약 관찰 | 건강관리 > 투약관리 (조건부) | 최신판에서 확인 필요 |
| 7 | 인지 변화 | 특이사항(기능 변화) | 변화상태 인지기능 호전/유지/악화 |
| 8 | 특이사항 | 특이사항 (글자 수 표시, 200자 경고) | 특이사항 |
| 9 | 다음 확인사항 | 칸 없음 (기관 내부 메모) | 칸 없음 (기관 내부 메모) |

"제공 지원" 카드 안에는 하위 칩(세면·목욕·체위변경·배설·이동·말벗)을 둡니다. 재가는 지원별 제공시간(분)과 배변 실수 횟수를 함께 받습니다. 말하지 않은 시간은 추정하지 않고 "언급 없음"으로 둡니다.[17][15]

**표현 충돌 규칙**은 v0.5와 같습니다. 서식 칸 이름 → 데모용 용어 목록(교재 본문 용어) → 용어집 순서로 근거를 쓰고, 관찰을 진단명으로 올리지 않으며("욕창"이 아니라 "엉덩이 부위 발적 관찰"), 뜻이 둘 이상이면 채우지 않고 "확인 필요"로 둡니다.[1][15]

## 시연

시연은 세 가지입니다. ① 시설 기록 한 건(별지 제16호), ② 재가 방문요양과 되돌리기(별지 제12호), ③ 교육용 기관 연습과 도우미. 단계별 내용은 시연 시나리오와 일정 v1.0에 있습니다.[26]
