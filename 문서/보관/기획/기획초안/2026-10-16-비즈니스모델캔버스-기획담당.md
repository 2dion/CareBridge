Oct 6, 2026 · @EUN GO

## 1. 미션

"언어가 돌봄 기록의 장벽이 되지 않도록, 누가 돌보든 어르신의 상태가 정확하게 기록되고 전달되게 한다."

- 어르신: 돌보는 사람이 바뀌어도 내 상태가 정확히 전달되는 것
- 외국인 요양보호사: 실수로 지적받지 않고 전문가로 인정받는 것
- 기관: 인력난 속에서도 기록 품질과 평가 점수를 지키는 것
- 범위: 임금·채용 차별·인력 기준 같은 제도 문제는 다루지 않고, 언어와 기록 장벽만 맡는다

## 3. 핵심 활동

모국어 관찰 메모를 근거가 남는 한국어 공식 기록으로 바꾸고, 담당자 검토까지 한 흐름으로 잇습니다.

| 구분 | 활동 | 시기 |
| --- | --- | --- |
| 서비스 | 모국어 메모 → 급여제공기록지 초안, 근거·미기재·확인 요청 표시, 담당자 검토·승인 | 이번 프로젝트 |
| 서비스 확장 | 응급 보고 문장, 교대 인수인계 요약, 어르신 말(사투리) 이해 지원, 내 기록으로 배우는 현장 한국어 | 이후 |
| 데이터 | 장기요양 용어집 구축, 합성 정답셋·유학생 평가셋 관리, 담당자 수정 이력으로 정확도 개선 | 이번 프로젝트부터 |
| 사업 | 양성대학·시설 시범 운영, ERP 제휴, 지자체 시범사업 제안 | 이후 |

| 이미 사용 가능한 역량 | 확보해야 하는 역량 |
| --- | --- |
| LLM API, 다국어 음성인식, 웹앱 개발 도구, 표준교재·법정 서식 | 원어민 검수 인력, 장기요양 현장 지식, 언어별 정확도 검증 체계, 개인정보 보호 설계 |

## 7. 가치 제안

"외국인 요양보호사가 모국어로 말하면, 근거가 남는 한국어 기록 초안이 되고, 최종 판단은 담당자가 한다."

| 이해관계자 | 해결하는 문제 | 만드는 가치 |
| --- | --- | --- |
| 외국인 요양보호사 | 일지·의학용어·응급 보고·사투리 장벽 | 지적받지 않는 정확한 기록, 실수에 대한 불안 감소 |
| 검토자(사회복지사·팀장) | 외국인 직원 기록을 다시 쓰는 부담 | 다시 쓰지 않고 확인만 해서 승인, 빠진 항목이 미리 표시됨 |
| 시설장 | 인력난, 평가 대응, 사고 시 책임 | 외국인 채용의 의사소통 부담 감소, 평가에 맞는 기록, 승인 이력이라는 근거 |
| 어르신·보호자 | 외국인 돌봄에 대한 불안 | 누가 돌보든 같은 품질의 기록, 상태 변화의 빠른 공유 |
| 양성대학 | 졸업생의 현장 적응과 취업 | 실습 단계부터 기록 연습, 취업 후 이탈 감소 |
| 정부·지자체 | 외국인 돌봄인력의 낮은 정착률(자격자 중 근무 28.7%) | 정착을 돕는 디지털 기반, 정책 효과 데이터 |

기존 대안과의 차이: 번역기는 번역만 하고 서식·근거·책임 구조가 없습니다. 요양 ERP는 서식은 있지만 외국어 입력이 없습니다. 팀장이 다시 쓰는 방식은 정확하지만 사람에 의존합니다. 케어브릿지는 다국어, 장기요양 서식, 담당자 검토를 한번에 갖춘 빈자리를 노립니다.

| 사회 | 기록 누락·오류로 인한 안전사고 예방 | 필수 항목 누락률, 위험 신호 조기 발견 건수 |
| 사회 | 이주민 돌봄에 대한 신뢰와 수용성 향상 | 보호자 신뢰도 설문 |
| 경제 | 검토자의 재작성 시간 절감 | 기록 1건당 작성·검토 시간 |
| 경제 | 기관 평가 대응 부담 감소, 외국인 채용 부담 완화 | 평가 지적 건수, 채용 의향 변화 |

혜택을 보는 사람: 외국인 요양보호사, 검토자, 기관, 어르신·보호자, 양성대학, 정부·지자체, 그리고 확장 단계에서는 기록이 어려운 내국인 신입·고령 요양보호사.

## 9. 부정적 영향과 대응

| 부정적 영향 | 대응 |
| --- | --- |
| 오역으로 인한 잘못된 돌봄 판단 | 근거 표시, 미기재 처리, 응급 문장은 정해진 틀로 고정 |
| 담당자가 AI 초안을 그대로 승인(자동화 편향) | 확인 필요 칸을 해결해야 승인되도록 설계 |
| 외국인 직원 감시·평가 도구로 오용 | 개인별 오류 통계를 인사 평가에 쓰지 않는다는 이용 정책, 학습 기록은 본인만 열람 |
| AI에 의존해 한국어 실력이 늘지 않음 | 고친 표현을 복습하는 학습 기능(확장), 직접 작성 비중을 단계적으로 확대 |
| 저임금 구조를 굳히는 데 쓰인다는 비판 | 인력 대체가 아닌 기록 지원 도구로 한정, 처우 논의와 분리 |
| 기록이 획일화되어 관찰의 뉘앙스가 사라짐 | 원문 메모를 기관 안에 함께 보관, 특이사항은 서술형 유지 |
| 개인정보 유출 | 가명처리, 국내 저장, 접근 기록, 최소 수집 |
| 스마트폰·디지털이 어려운 사람의 소외 | 공용 태블릿, 음성 입력, 수기 메모 사진 인식(확장) |

## 10. 비용

가장 큰 비용은 개발비가 아니라 언어별 검수와 신뢰 확보에 드는 사람 비용입니다.

| 구분 | 항목 |
| --- | --- |
| 초기 개발 | 웹앱·관리자 화면 개발, AI 처리 과정 구축, 용어집·정답셋 구축 |
| 운영(사용량에 비례) | AI·음성인식 호출비(기록 1건마다 발생), 클라우드 저장·트래픽 |
| 검증·품질 | 언어별 원어민 검수, 간호·사회복지 자문, 정기 정확도 평가 |
| 보안·법무 | 개인정보 영향 평가, 보안 점검·인증, 법률 자문 |
| 영업·교육 | 기관 도입 지원, 모국어 사용 안내 영상, 고객 지원 |
| 제휴 | ERP 연동 개발, 수익 배분 |

절감 방법: 같은 표현은 결과를 저장해 다시 쓰고, 단순 변환은 저렴한 모델에 맡기고, 응급 문장은 정해진 틀로 고정해 AI 호출을 줄입니다.

## 11. 수익

돈은 요양기관이 내고 요양보호사는 무료로 씁니다. 기관이 돈을 낼 이유는 담당자의 재작성 시간과 기록 누락에 따른 평가·사고 위험을 줄이는 것입니다.

| 수익 모델 | 대상 | 방식 |
| --- | --- | --- |
| 기관 구독 | 외국인 요양보호사를 고용한 시설·재가기관 | 기본료 + 외국인 요양보호사 1인당 월 요금. 기존 ERP가 월 1만\~3만 원대라 그 수준에서 출발(가정) |
| ERP 제휴 | 이지케어·케어포 등 | 추가 기능 판매 수익 배분 또는 이용료 |
| 교육용 라이선스 | 양성대학, 요양보호사 교육원 | 실습 기록 연습용 연간 라이선스 |
| 공공 사업 | 지자체(대전형 외국인 돌봄인력 지원), 사회서비스원 | 시범사업 위탁, 바우처 연계 |
| 초기 자금 | KEIT 공모전 상금, 정부 R&D·창업 지원 | 1년차 개발·시범 운영 비용 |
| 확장 | 내국인 신입·고령 요양보호사 | 같은 엔진으로 '쉬운 기록 도우미' 판매 |

**단계별 계획(가정)**

1. 1년차: 공모전·지원금으로 개발, 양성대학·시설 2\~3곳 무료 시범 운영
2. 2년차: 양성대학 교육용 라이선스, 지자체 시범사업으로 첫 매출
3. 3년차: 2028년 하반기 양성대학 졸업생 현장 투입에 맞춰 ERP 제휴로 기관 구독 확대, 내국인 요양보호사로 대상 확장

시장 규모(추정): 외국인 요양보호사를 고용한 기관만 보면 연 5\~15억 원, 전체 장기요양기관(2025년 2만 9,734곳)으로 넓히면 연 약 107억 원. 두 수치 모두 요금과 도입률을 가정한 값입니다.

## 블록 간 연결

캔버스가 설득력을 갖는 것은 블록끼리 서로 맞물릴 때입니다.

- 장벽(6) → 활동·이네이블러(3·5): 오역은 근거 대조·역번역과 근거 표시로, 민감정보는 가명처리 모듈로 해결
- 가치 제안(7) → 수익(11): 검토자의 재작성 부담을 줄이는 것이 기관이 돈을 내는 이유
- 부정적 영향(9) → 미션(1): 감시 금지·인력 대체 아님이 "언어·기록 장벽만 맡는다"는 미션과 일치
- 비용(10) → 파트너(2): 가장 큰 비용인 언어 검수를 양성대학 협력으로 낮춤
