# (기획 담당) PM용 기획서 검토

검토일: 2026-10-06 | 기준: 「(기획 담당) PM용 기획서」 및 저장된 코디세이·공모전 자료

## 검토 결론

v1은 사용자 두 역할, 필수 기능 5개, 베트남어·시설급여 한정 범위, 사람의 최종 승인, 비교 평가를 갖추어 개발 기획의 출발점으로 적합하다. 코디세이 상세기획서에서는 이 범위를 유지하되, 현장 문제에 대한 가설과 검증된 사실을 구분하고 기능별 완료 조건·평가 절차·팀별 산출물·일정을 구체화한다. 현재 구현, 사용자 섭외, 멘토 승인, 성능 결과가 확보되었다고 볼 근거는 없다.

## 유지할 내용

- 핵심 사용자: 외국인 요양보호사와 기관 기록 담당자.
- 베트남어 텍스트 입력, 시설급여 서식 1종, 모바일 웹·PC 검토 화면.
- 필수 F1~F5를 먼저 완성하고 응급 보고·음성 입력은 별도 결정.
- 가상 돌봄 사례만 사용하며 AI는 초안 생성과 모국어 설명에 사용.
- 원문 근거 표시, 미기재 처리, 사람 확인 2단계, 수정·승인 이력.
- 단순 AI 구조화 방식 및 기존 작성 방식과 비교하고 협업 기록을 남기는 계획.

| 높음 | 서식 항목 미확정인데 법정 기록지로 설명 | 시설급여 서식의 버전·원문·항목표를 10/10까지 확정. 서비스 PDF는 검증용 초안·승인본이며 공식 제출을 대체한다고 주장하지 않음 |
| 높음 | “검사와 사람 확인이 걸러낸다”, “이름 없는 내용”의 표현이 보장처럼 읽힘 | 숫자·근거·형식 검사는 일부 오류만 탐지. 문장이 원문에 있어도 번역 의미가 틀릴 수 있음. 가명처리 후에도 재식별 가능성과 건강 정보가 남을 수 있음을 명시 |
| 높음 | 역번역만으로 내용 정확성 확인 가능하다는 인상 | 같은 모델의 오류가 역번역에서도 유지될 수 있음. 독립 언어 검수와 기록 적합성 검수를 분리 |
| 높음 | 검수자와 요양기관 담당자 접근 경로 미확보 | 10/8까지 언어 검수자·현장 검수자 확보 여부를 결정. 유학생 참여만으로 현장 적합성을 검증했다고 해석하지 않음 |
| 높음 | “필수 항목 누락률”이 서식 전체 공란과 원문 정보 누락을 혼동할 수 있음 | 원문에 있는 정답 정보의 누락률과 서식 미기재율을 별도로 정의. 원문에 없는 내용을 비우는 것은 오류로 세지 않음 |
| 중간 | 승인 전 확인 요청 해결 조건이 모호 | 추가 관찰·정정 또는 정보 확인 불가 사유를 구분해 해결. 서식 필수 항목은 임의의 사유 입력만으로 승인하지 않도록 항목 기준 확정 |
| 중간 | 재생성·반려·동시 수정의 처리 기준 부족 | 버전별 원문·초안·확인·수정 이력을 연결하고 변경 시 확인을 다시 받음. 승인본은 잠금, 정정은 새 버전 |
| 중간 | 수치·시장 규모·가격이 제출 근거로 사용되기에는 출처 부족 | v1 수치는 원문·기준연도·산식 확인 전 제출 요약에서 제외. 사용 의향과 지불 의향을 별도로 검증 |
| 중간 | 기술 스택·비용·지연 목표가 미정 | 담당자 선택과 팀 승인 사항으로 표시하고 기능 기준만 우선 작성 |
| 중간 | 일부 도식과 중간 일정이 embedded content로만 남아 있음 | 텍스트 흐름·상태 전이·마일스톤 표로 재작성. 원문에서 읽히지 않은 날짜는 계획안으로 표시 |
| 낮음 | “손댁니다”, “뗰습니다” 등 오탈자 | 새 문서는 교정된 표현 사용. v1 원본은 변경하지 않음 |

## 문서로 확인한 기준

1. HWPX 양식은 파일명이 ‘상세기획서’이나 본문 제목은 ‘Final-Project 프로젝트 기획안’이다. 도메인·팀명·프로젝트명·팀장과 네 본문 항목을 요구하며, ‘2쪽 이내로 자유롭게 작성’이라고 명시한다.
2. 설명회 7쪽: 결과물 제출 2026-11-08 18:00, 평가 11/12~13(변동 가능). 9쪽: 상세기획서에 대한 전담 멘토 주제 승인. 12~15쪽: 기획 30, 기술 20, 실용 10, 협업 30, 발표 10점. 15~16쪽: 팀장 제출, 제출 후 수정 불가, 발표 10분·질의응답 10분.
3. 공모전 공고 3~4쪽: 사전질의 10/7까지, 접수 10/31 24:00까지. 7쪽: 입상작 기반 결과물의 지식재산권 50:50 공동 소유가 원칙이며 상세 사항은 협의. 후보작 구현이 가점 인정 대상인지는 답변 확인 필요.
4. 공모전 공고 6쪽: 참가 인원 외 인원에게 사전검증·서류 작성 등을 용역·하도급·분담할 수 없다고 명시한다. 외부인의 인터뷰·사용성 테스트·언어 검수가 허용되는 검증 참여인지, 개발 업무 분담으로 해석되는지 문의 항목에 포함한다.
5. 개인정보 보호법 제23조는 건강 정보를 민감정보로 다룬다. 가명처리만으로 실제 서비스의 외부 AI 제공 조건이 충족된다고 판단하지 않는다. 이번 기획은 가상 사례 범위로 작성한다.

## 검토 범위와 출처

v1과 저장된 설명회·공모전 공고·후보작 목록, HWPX 양식을 읽어 대조했다. v1의 언론·통계·논문 원문, 별도 ‘1단계 문제 조사 보고서’, V2는 이번 폴더에서 확인하지 못했다. 따라서 통계 수치·효과·시장 규모는 검증된 사실로 재사용하지 않았다. 개발 및 사용자 테스트도 수행한 상태가 아니다.
