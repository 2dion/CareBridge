# 케어브릿지 시연 시나리오와 일정 v1.0

Oct 16, 2026 · @2dion

## 시연 시나리오 3개

세 시나리오가 기획의 세 약속을 하나씩 보여 줍니다. ① 시설 기록을 음성 하나로 완성, ② 재가 기록과 담당자 2단계 확인, ③ 교육기관 먼저 + 도우미.\[1\] 모두 합성 사례이고, 화면 ID는 화면 설계 v1.0과 같습니다.\[2\]

### 시나리오 1. 시설 기록 한 건 (별지 제16호)

**인물:** 베트남 출신 요양보호사 ‘마이’, 요양원 어르신 ‘김○○’(와상, 복약 대상), 담당자 ‘박 사회복지사’.

1. W1(오늘)에서 김○○ 카드를 누른다.
2. W2(음성 메모)에서 \[시작\] → 한국어와 베트남어를 섞어 말한다. “아침에 세수해 드리고 두 시간마다 자세 바꿨어요. 점심은 조금 드셨어요. Bà ngủ không ngon(밤에 잘 못 주무심). 약은 드셨어요.” → \[정지\].
3. W3(기록 초안 확인): 제공 지원·수면·복약은 ‘관찰’, 식사는 ‘조금’이 모호해 **‘확인 필요’**, 인지 변화는 ‘언급 없음’.\[3\]
4. 식사 카드를 누르고 말로 보탠다. “죽 반 안 되게 드셨어요.” → ‘1/2 미만’, ‘관찰’로 바뀜. 🔊로 한국어 문장을 들어 본다.
5. 나머지는 \[맞아요\] → \[담당자에게 보내기\].
6. 담당자 PC: R1(검토 대기)에 1건 → R2(검토 화면)에서 항목을 눌러 왼쪽 원문의 근거 문장이 강조되는 것을 보여 준다. 특이사항 글자 수를 보고 \[복사\] → \[승인\].
7. R3(승인한 기록): 4단계 이력, \[인쇄·PDF\]로 별지 제16호 모양 출력, 잠긴 \[가족과 공유\].

**보여 주는 것:** 말 한 번으로 초안, AI가 지어내지 않고 모호한 것을 물어 봄, 한국어가 위·모국어가 아래.

### 시나리오 2. 재가 방문요양과 되돌리기 (별지 제12호)

**인물:** 같은 요양보호사, 재가 어르신 ‘이○○’(평일 14:00\~17:00 방문).

1. W2에서 말한다. “두 시부터 다섯 시까지 있었어요. 목욕 도와드리고 청소했어요. 한 시간 동안 이야기 나눴는데 오늘이 며칠인지 두 번 물어보셨어요.”
2. W3: 방문 시점 14:00\~17:00, 제공 지원에 신체활동·가사·정서 지원 칩과 제공시간(분) 칸, 인지 변화 “오늘 날짜를 두 번 물으심”(비교가 없어 호전/유지/악화는 ‘확인 필요’).\[3\]\[4\]
3. 작성자가 지원별 분을 입력하다 합이 200분이 되어 방문 시간(180분)을 넘는다 → ‘확인 필요’ 표시가 뜨지만 그대로 보낸다.
4. R2: 담당자가 \[되돌리기\], 사유 “제공시간 합계가 방문 시간보다 많습니다.”
5. 작성자 W4(기록함)에 ‘되돌아옴’, 사유가 한국어+베트남어로 보인다 → W3에서 고쳐 다시 보냄.
6. R2: 인지기능 변화상태를 담당자가 ‘유지’로 고르고 \[승인\] → R3에서 별지 제12호 모양 인쇄.

**보여 주는 것:** 시설과 재가를 모두 지원, 서버 검사(시간 합), 담당자 2단계 확인과 이력.\[5\]

### 시나리오 3. 교육용 기관 연습과 도우미

**인물:** 요양보호사 교육원 교육생, 강사.

1. 교육용 기관 계정으로 로그인 → 모든 화면 상단에 ‘연습용 · 합성 사례’ 띠.\[6\]
2. W6(도우미)에서 말로 물는다. “어르신이 식사를 안 하시려고 하면 어떻게 해요?” → 교재 내용으로 답하고 장·쪽 출처, 한국어 위·베트남어 아래.
3. 다시 물는다. “‘진지 잡수세요’가 무슨 뜻이에요?” → ‘식사하세요’라는 뜻을 풀어 줌.
4. 합성 사례 어르신으로 시나리오 1과 같은 기록을 연습해 보낸다.
5. 강사 R2: 수정·승인 버튼 없이 항목별 코멘트 “섭취량을 숫자로 말해 보세요” → \[코멘트 보내기\].
6. 교육생 W3에서 코멘트가 번역되어 보인다.

**보여 주는 것:** “교육기관에 먼저 적용”의 실체, 기록과 도우미의 분리, 실제 어르신 정보 없이 연습.\[1\]\[6\]

- [ ] 데모 기관 2개: 일반 기관(시나리오 1·2), 교육용 기관(시나리오 3)\[6\]

- [ ] 시나리오별 말할 문장 대본(위 따옴표 문장)
- [ ] 미리 처리해 둔 결과(네트워크·AI가 느리거나 실패할 때 보여 줄 백업)\[7\]
- [ ] 교재 상황 대처 매뉴얼을 manual\_sections에 넣기(식사 거부 절 포함)
- [ ] 시연 화면 캐처와 구동 영상(코디세이 평가가 화면 캐처·GIF·영상 링크를 봄)\[8\]
- [ ] 시연 전날 Supabase 프로젝트 열어 두기(무료 요금제 일시 중지 방지)\[7\]
