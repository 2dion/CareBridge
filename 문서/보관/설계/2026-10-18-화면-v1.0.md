# 케어브릿지 화면 설계 v1.0

Oct 16, 2026 · @2dion

## 범위와 v0.5에서 바뀐 점

이 문서는 개발자가 보고 바로 화면을 만들 수 있도록, 기획안 v0.5의 ‘메뉴와 화면’을 화면별로 풀어 씁니다.\[1\]\[2\] 화면 ID는 v0.5와 같고, 항상 이름을 함께 씁니다. 기술은 기술 선택 v1.0(반응형 웹앱 하나)을 따릅니다.\[8\]

**v0.5에서 바뀐 점 (10/16 결정)**

| 바뀐 것 | 내용 | 근거 |
| --- | --- | --- |
| 기록 항목 8개 → 9개 | ‘인지 변화’ 추가(기억·날짜·사람 헷갈림 → 호전/유지/악화). 기분은 따로 두지 않음 | \[3\]\[7\] |
| W6(도우미) | 여유 시 → **MVP 포함** | \[3\] |
| R3(승인한 기록) 인쇄·PDF | 여유 시 → **MVP 포함** | \[3\] |
| 특이사항 200자 | 글자 수 표시 + 넘으면 경고만(입력은 막지 않음) | \[3\] |
| W2(음성 메모) | 시작·끝 모두 버튼으로 직접, 자동 정지 없음 | \[4\] |
| 서식 | 시설급여(별지 제16호)와 재가 방문요양(별지 제12호)을 모두 지원 | \[6\]\[7\] |
| 교육생 연습 | 켜고 끄는 교육 모드 없이 ‘교육용 기관’ 계정으로 분리 | \[5\] |

**9개 항목 (화면에 나오는 순서):** ① 방문 시점 ② 제공 지원 ③ 식사 ④ 수면 ⑤ 불편감 표현 ⑥ 복약 관찰 ⑦ 인지 변화 ⑧ 특이사항 ⑨ 다음 확인사항. 항목마다 상태는 ‘관찰’ / ‘언급 없음’ / ‘확인 필요’ 중 하나입니다.\[1\]

## 화면 흐름

&#91;embedded content: 화면 흐름 · 작성자 4단계, 담당자 3단계, 되돌리기 1갈래\]

담당자가 되돌리면 작성자의 W4(기록함)에 ‘되돌아온 기록’으로 뜨고, 누르면 W3(기록 초안 확인)이 사유를 맨 위에 둔 채 다시 열립니다.\[1\] W6(도우미)는 기록 흐름과 따로, 하단 탭에서 언제든 엽니다.

## 모든 화면 공통 규칙

| 규칙 | 내용 |
| --- | --- |
| 한국어 위, 모국어 아래 | 작성자 화면의 모든 안내·항목은 한국어를 먼저, 그 아래 작은 글씨로 모국어(베트남어). 최종 기록은 항상 한국어\[1\]\[9\] |
| 듣기 버튼 | 한국어 문장 옆마다 🔊. 누르면 브라우저 음성으로 읽어 줌\[8\]\[9\] |
| 기기와 화면 크기 | 기기를 정해 두지 않음. 모든 화면이 휴대폰 세로(너비 360px부터)와 PC 가로(1280px 기준)에서 다 열림. 작성자가 PC로 쓰거나 담당자가 휴대폰으로 검토해도 됨. 기본 배치만 작성자=휴대폰, 담당자=PC 기준으로 먼저 만듦\[11\] |
| 글은 적게, 그림으로 | 한 화면에 할 일 하나. 긴 설명 대신 아이콘+짧은 말(예: 🎤 말하기, ✏️ 쓰기, ✅ 맞아요). 안내 문장은 한 줄, 더 필요하면 눌러서 펼침\[11\] |
| 문화 차이로 헷갈리지 않게 | 나라마다 뜻이 다른 손짓·색 아이콘(👍, 👌, 빨강=좋음 등)은 쓰지 않음. 날짜는 ‘10월 16일’, 시간은 ‘오후 3:00’처럼 글자로 함께. 아이콘에는 항상 글자 이름을 붙임. 베트남어 팀 자체 검증 때 같이 확인\[11\] |
| 누르기 쉬운 버튼 | 작성자 화면 버튼은 손가락으로 누를 수 있는 크기(높이 48px 이상), 글자 크기는 W5(내 정보)에서 3단계 |
| 항목 상태 배지 | 관찰(초록) / 언급 없음(회색) / 확인 필요(주황). 색만으로 구분하지 않고 글자도 함께 |
| AI 초안 표시 | AI가 채운 내용에는 ‘AI 초안’ 표시. 작성자가 \[맞아요\]를 누르거나 고치면 사라짐\[1\] |
| 시설·재가 차이 | 어르신 정보의 ‘급여 종류’로 정해짐. 재가(별지 제12호)면 W3·R2에 방문 시작·종료 시간과 지원별 제공시간(분) 칸이 더 나옴\[6\]\[7\] |
| 처리 중·오류 | AI 처리 중에는 단계 표시(“글자로 바꾸는 중 → 항목 채우는 중”). 실패하면 \[다시 시도\]와 ‘글로 쓰기’를 보여 주고, 쓰던 내용은 임시 저장\[8\] |
| 개인정보 | 어르신은 가명으로 표시. 데모는 합성 데이터만 사용\[1\] |

## 작성자 화면 (휴대폰)

### W0(사용 안내)

- **보이는 것:** 첫 실행 때 3장(① 말로 메모 남기기 ② 빈 칸 채우기 ③ 담당자가 승인하면 끝), 언어 선택(한국어만 / 한국어+베트남어).\[1\]
- **할 수 있는 것:** \[다음\] \[건너뛰기\]. W5(내 정보)에서 다시 볼 수 있음.
- **저장:** 언어, 안내를 봤는지.

### W1(오늘)

- **보이는 것:** 오늘 날짜, 담당 어르신 카드(가명, 시설/재가, 방문·돌봄 시간, 상태 배지: 작성 전 / 임시 저장 / 보냄 / 되돌아옴 / 승인됨). 되돌아온 기록이 있으면 맨 위에 주황 띠.\[1\]
- **할 수 있는 것:** 카드를 누르면 상태에 따라 W2(음성 메모) 또는 W3(기록 초안 확인)으로.
- **빈 상태:** “오늘 담당 어르신이 없습니다. 담당자에게 문의하세요.”

### W2(음성 메모)

- **보이는 것:** 어르신 이름, 큰 \[시작\] 버튼, 녹음 안내 문구(“오늘 도운 일, 식사, 수면, 달라진 점을 편하게 말해 주세요”, 한국어+모국어). 녹음 중에는 타이머와 빨간 표시, \[정지\] \[삭제\].\[4\]
- **할 수 있는 것:** \[시작\] → \[정지\] → 자동으로 처리 시작. 자동 정지는 없음. \[글로 쓰기\]로 바꾸면 글자 입력창.
- **예외:** 마이크 권한 거부 → 권한 켜는 방법 안내 + \[글로 쓰기\]. 네트워크 끊김 → 폰에 잠시 보관 후 다시 보냄. 글자로 바뀜 뒤 음성은 삭제.\[1\]

### W3(기록 초안 확인) — 핵심 화면

- **보이는 것:** 9개 항목 카드. 접힌 상태는 두 줄(한국어 요약 + 모국어) + 상태 배지 + \[맞아요\] \[달라요\]. 펼치면 ‘내가 한 말’(근거 문장)과 용어 뜻. 되돌아온 기록이면 담당자 사유가 맨 위.\[1\]
- **할 수 있는 것:** 빈 항목(언급 없음)을 누르면 말하기·쓰기와 예시 문장. \[달라요\] → 그 항목만 다시 말하거나 고침. 사투리·일상 표현은 짐작 뜻을 보여 주고 ‘확인 필요’. \[임시 저장\] \[담당자에게 보내기\].
- **특이사항:** 글자 수 표시(예: 182/200), 200자를 넘으면 주황 경고만(보내기는 가능).\[3\]
- **재가(별지 제12호):** ① 방문 시점에 시작·종료 시간, ② 제공 지원에 신체·인지활동·인지관리·정서·가사 지원별 제공시간(분) 칸.\[7\]
- **보내기 조건:** 모든 항목에 \[맞아요\]를 누르거나 고친 뒤. ‘확인 필요’가 남아 있어도 보낼 수는 있고, R2(검토 화면)에 그대로 표시됨.

### W4(기록함)

- **보이는 것:** 상태별 탭(임시 저장 / 보냄 / 되돌아옴 / 승인됨), 날짜·어르신. 되돌아온 기록은 사유(한국어 + 번역).\[1\]
- **할 수 있는 것:** 누르면 W3(기록 초안 확인). 승인된 기록은 읽기만.

### W5(내 정보)

- 언어, 글자 크기(3단계), 내 단어장(여유 시), 사용 안내 다시 보기, AI 사용 원칙·개인정보 안내, 로그아웃.\[1\]

### W6(도우미) — MVP 포함

- **보이는 것:** 채팅 화면, 상단 고정 고지 “건강·안전 문제는 담당자에게 먼저 보고하세요”, 답변 아래 교재 장·쪽 출처.\[1\]\[3\]
- **할 수 있는 것:** 음성(시작·정지 버튼) 또는 글로 질문. 상황 대처법, 사투리·일상 표현 뜻 묻기. 답변은 한국어 위, 모국어 아래, 🔊 듣기.
- **하지 않는 것:** 기록을 대신 쓰거나 고치지 않음(기록과 도우미는 별개). 교재에 없는 내용은 “교재에서 찾지 못했어요, 담당자에게 물어보세요”.\[2\]

## 담당자 화면 (PC)

담당자 화면은 한국어만 씁니다. 왼쪽에 메뉴(R1\~R4), 오른쪽에 내용을 두는 PC 배치입니다.\[1\]

### R1(검토 대기)

- **보이는 것:** 표(어르신, 시설/재가, 작성자, 방문·돌봄 시간, 확인 필요 개수, 받은 시각). 확인 필요가 많은 기록이 위로.\[1\]
- **할 수 있는 것:** 작성자·날짜·급여 종류 필터. 행을 누르면 R2(검토 화면).
- **빈 상태:** “검토할 기록이 없습니다.”

### R2(검토 화면) — 핵심 화면

- **왼쪽:** 작성자가 말한 원문(받아쓴 글 그대로)과 한국어 번역. 오른쪽 항목을 누르면 그 항목의 근거 문장이 왼쪽에서 강조됨.\[1\]
- **오른쪽:** 9개 항목 편집 칸, 상태 배지, ‘확인 필요’ 체크. 항목마다 ‘공식 기록지 칸’ 안내(시설이면 별지 제16호, 재가면 별지 제12호 칸 이름).\[6\]\[7\]
- **특이사항:** 글자 수 표시, 200자 넘으면 경고만, \[복사\] 버튼(스마트장기요양 앱에 붙여 넣기용).\[3\]
- **할 수 있는 것:** 항목 직접 수정(수정 전후가 이력에 남음), \[되돌리기\](사유 필수, 작성자에게는 번역돼서 보임), \[승인\].
- **승인 조건:** ‘확인 필요’가 남아 있으면 \[승인\] 전에 “확인 필요 2개가 남아 있습니다” 한 번 더 물음.

### R3(승인한 기록)

- **보이는 것:** 승인된 기록 목록과 상세. 상세에는 4단계 이력(작성 → 보냄 → 검토·수정 → 승인, 각각 누가·언제).\[1\]
- **할 수 있는 것:** \[인쇄·PDF\](MVP 포함): 별지 서식 모양의 인쇄용 화면, “공식 기록지 아님” 표시.\[3\]\[8\] \[가족과 공유\]는 잠긴 버튼(누르면 “승인 후, 고른 내용만 공유하는 기능입니다. 준비 중”).

### R4(어르신·작성자, 설정)

- **어르신:** 가명, 급여 종류(시설/재가), 담당 작성자 연결. 데모용 간단 목록으로 추가·수정.\[1\]
- **작성자:** 이름, 모국어, 초대 링크(또는 데모 계정).
- **설정:** 기관 정보(교육용 기관 여부는 읽기만), AI 사용 원칙.

## 교육용 기관에서 달라지는 점

화면은 같은 것을 쓰고, 기관에 ‘교육용’ 표시가 있을 때만 아래가 달라집니다. 켜고 끄는 스위치는 없습니다.\[5\]

| 화면 | 일반 기관 | 교육용 기관 |
| --- | --- | --- |
| 모든 화면 | 표시 없음 | 상단에 ‘연습용 · 합성 사례’ 띠 |
| W1(오늘) | 담당 어르신 | 합성 어르신 사례 |
| W2\~W4 | 그대로 | 그대로(교육생이 같은 흐름을 연습) |
| R2(검토 화면) | 담당자가 수정·승인 | 강사가 항목별 코멘트만(수정·승인 버튼 없음), \[코멘트 보내기\]\[10\] |
| R3(승인한 기록) | 승인본 | ‘코멘트 받은 연습’ 목록, PDF에 ‘연습용’ 표시 |
| R4 | 어르신·작성자 | 합성 사례·교육생 목록 |

v0.5 일정을 따르되, MVP에 들어온 W6(도우미)와 인쇄·PDF를 뒤쪽에 넣습니다.\[1\]\[3\] 자세한 일정은 ‘시연 시나리오와 일정’ 문서에서 정합니다.

2. **10/22 멘토링까지:** W1(오늘), R1(검토 대기), R3(승인한 기록) 목록 붙이기. 휴대폰·PC 브라우저로 시연.\[9\]
3. **10/23\~30:** 되돌리기 갈래, 재가(별지 제12호) 칸, W6(도우미), R3 인쇄·PDF, W0·W5, R4, 교육용 기관 표시.
4. **10/31 공모전 접수 → 11/8 파이널 제출:** 다듬기, 내 단어장(여유 시).
