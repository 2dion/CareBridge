- **배경:** 기술검토 v1.0~v1.4는 v1.0 설계 문서를 기준으로 썼고, 그 사이 v1.1(Agent, 승인 막기, 10/23 마감)이 나왔습니다. 두 묶음을 같이 읽으면 서로 다른 말을 하는 곳이 생깁니다.[1][2][3]
- **근거:** v1.1 문서 6개와 AGENTS.md(PR #4 브랜치, 공유 폴더 `design/v1.1/`), 기술검토 세 판, 팀장 10/19 전제 세 가지(아래), 저장소 main 2c7198c.[1][2][3][4]
- **사유:** 기술검토 v1.4가 가장 최신이고 v1.2 내용을 거의 다 담고 있어서 v1.4를 기준으로 비교하고, v1.0·v1.2에만 있는 것은 따로 적었습니다.

**전제 (팀장, 10/19)**

1. 파일 이름 규칙은 폴더 제안으로 해결됨. 검사 범위를 `문서/`·`참고자료/`로 좁힌 PR #3이 main에 합쳐짐(2c7198c).[4]

## 결론

기술 스택(Next.js · Vercel · Supabase · OpenAI STT · Claude API)은 v1.1과 기술검토가 같은 말을 합니다. 바꿀 것은 없습니다. 다만 **기술검토가 찾은 운영·보안 장치 대부분이 v1.1 설계 문서에 아직 안 들어갔고**, 그중 녹음 업로드 경로는 v1.1 API 계약과 정면으로 어긋납니다. v1.1 문서 안에도 **Agent 도구가 쓸 용어 목록 표가 데이터 구조에 없는** 빈 곳이 있습니다.

**v1.1 안의 빈 곳 (기술검토 v1.4 2장 '용어집'이 이미 짚은 것)**

- Agent 도구 ② 용어 검색(search_glossary)은 "교재 공식 용어 + 베트남어 고정 번역 + 교재 장·쪽"을 찾는데, **데이터 구조 v1.1의 표 11개에 용어 목록 표가 없습니다.** 시연·일정 v1.1은 데이터 담당이 10/19~21에 "용어 목록 데이터를 DB에" 넣는다고 적었지만 넣을 표가 정해지지 않았습니다. v1.4의 `glossary`(일상어, 기록 용어, 베트남어 뜻, 쉬운 풀이)에 교재 장·쪽 칸을 더해 v1.1에 넣으면 됩니다.
- 도구 ① 서식 기준 조회(get_form_spec)가 쓰는 서식 기준 데이터(칸·선택지)도 `form_field_map`이라는 이름만 있고 표 목록에는 없습니다. 표로 둘지 코드 상수로 둘지 BE가 정하고 데이터 구조에 한 줄 적어야 합니다.

| Secret Scanning을 못 써서 gitleaks 필요 (v1.4 5장) | 공개 저장소는 비밀 키 검사와 push 차단이 무료. gitleaks는 선택으로 내려감 |

**전환 전에 꼭 볼 것:** 공개하면 커밋 기록 전체가 공개되고, 나중에 파일을 지워도 기록에 남습니다. 지금 저장소에는 ① 인터뷰 기록(실명·답변), ② 교재·양성지침 PDF 원본(66MB 포함, 재배포 문제 가능), ③ 10/31 공모전 전에 아이디어가 드러나는 기획·설계 문서가 있습니다. 공개 후에는 API 키가 커밋에 한 번만 들어가도 바로 노출됩니다.

## 6. 평가

- **기술검토 v1.4는 쓸 만합니다.** 무료 우선 원칙, 팀 문서끼리 어긋나는 6곳 정리, 녹음 삭제 장치, 심사위원 접속 문제는 v1.1이 놓친 것을 정확히 짚었습니다. 약점은 기준이 v1.0이라는 것 하나입니다. 그래서 상태 값·승인 칸 이름·Agent 상한이 v1.1과 다릅니다.
- **v1.1은 기능·흐름 설계는 촘촘하지만 운영 쪽이 비어 있습니다.** Agent·승인·테스트는 자세한데, 녹음 파일이 어디로 가는지, 키 없는 팀원이 어떻게 개발하는지, 심사위원이 어떻게 들어오는지가 없습니다. 이 셋은 첫 코드 PR부터 영향을 줍니다.
- **가장 급한 것은 녹음 업로드 경로입니다.** v1.1 API 계약대로 FE가 음성 파일을 서버로 보내면, 녹음이 길어질 때 Vercel 요청 크기 제한(4.5MB)에 걸립니다. v1.1은 자동 정지도 없어서 길이를 막을 장치가 없습니다. BE·FE가 공통 계약을 확인하기 전에 고쳐야 합니다.
- **일정은 이미 하루 밀렸습니다.** 시연·일정 v1.1은 10/17~18에 "빈 화면이 배포 주소에서 열림"을 끝낼 계획이지만, 저장소에 아직 코드가 없고 Vercel 배포는 멈춰 있습니다(2c7198c 기준).
