# 용어집 v1.0 — 화면·코드·문서가 같이 쓰는 이름

2026-10-29 · 팀장(2dion) 결정, Claude 정리

- **목적:** 같은 것을 화면·코드·설계 문서에서 한 이름으로 부릅니다.
- **배경:** 상태 이름을 10/27에 새로 정했지만 문서·주석·베트남어에 옛 이름(보냄, 되돌아온 기록, 기록함 등)이 남았고, 화면 번호도 피그마 M·D 번호와 섞였습니다(이슈 #94).
- **근거:** 결정 [2026-10-29-용어통일](../결정/2026-10-29-용어통일.md)(14개 결정), [상태 이름 결정](../결정/2026-10-27-상태이름.md).
- **사유:** 용어 표를 화면 문구 문서 안에 두면 찾기 어려워, 설계 폴더의 문서 하나로 뗐습니다. 화면 배치·동작은 [화면 설계 v1.3](화면-v1.3.md)이 기준이고, 이 문서는 이름만 정합니다.

> [!NOTE]
> 이 문서는 앱 안에서 쓰는 이름의 목록입니다. AI가 쓰는 **교재 용어 목록**(일상 표현 → 교재 용어, DB 표 `glossary`)은 [data/glossary](../../data/glossary/glossary-v0.3.md)에 따로 있습니다.

**바꾼 곳:** 화면 글자·코드 주석은 PR #130에서 이 표대로 고쳤습니다. 교육용 기관 화면에서 교육생·강사로 보이게 하는 일(`organizations.is_training`)은 QA 테스트 뒤에 합니다. 영어 이름은 바꾸지 않습니다.

## 표 읽는 법

| 칸 | 뜻 |
| --- | --- |
| 쓰는 이름 | 화면·문서·발표에서 쓰는 한국어 |
| 쓰지 않는 이름 | 없앨 이름. (서식) = 법정 서식·교재 원문이라 인쇄·출처에서만 씀 |
| 영어 이름 | DB 표·칸·값, API, 코드 이름. **바꾸지 않고 대응만 적음** |
| 베트남어 | 병기할 때 쓰는 말(원어민 검수 전) |
| 화면 | 쓰이는 화면 번호 |

## 화면 번호

화면 번호는 **W·R·A 하나만** 씁니다. 피그마의 M(Mobile)·D(Desktop) 번호는 쓰지 않습니다. 피그마 '개발 v1.0'은 화면 초안·참고 자료로만 두고, 화면 이름·글자의 기준은 코드와 이 문서입니다. 번호 없는 하위 화면은 `상위 번호 · 이름`으로 부릅니다(예: `W3 · 항목 고치기`).

| 글자 | 뜻 | 누가·어디서 |
| --- | --- | --- |
| **W** | Worker | 작성자(교육용 기관은 교육생) 화면, 휴대폰 |
| **R** | Reviewer | 관리자(교육용 기관은 강사) 화면, PC |
| **A** | Account | 계정 화면, 둘 다 |

| 번호·이름 | 하위 화면 | 경로 | 옛 피그마 번호(참고) |
| --- | --- | --- | --- |

| W3 기록 초안 확인 | 정리 중 · 항목 고치기 · 내용 보태기 · 전송 완료 | `/records/:id`, `/records/:id/items/:key`, `/records/:id/sent` | M10, M12~M17 |

**하단 탭(작성자):** 오늘 / 기록 / 도우미 / 내 정보 (한국어만). **PC 메뉴(관리자):** 검토 대기 / 승인한 기록 / 어르신·작성자 / 설정.

## 사람·기관

| 쓰는 이름 | 쓰지 않는 이름 | 영어 이름 | 베트남어 | 화면 |
| --- | --- | --- | --- | --- |
| 작성자 / 교육생(교육용 기관) | 요양보호사·보호사(앱 안에서) | `profiles.role = worker`, `worker_id` | — | W 전부, R1·R4 |
| 관리자 / 강사(교육용 기관) | 담당자, 검토자, 기관 담당자 | `role = reviewer`, `approved_by` | người quản lý (강사는 확인 필요) | R 전부, W 안내 |
| 어르신 | 수급자·대상자(서식), 이용자 | 표 `residents`, `resident_id` | người cao tuổi | W1·W4·R 전부 |
| 가명 | — | `residents.alias` | — | R4 |
| 기관 / 교육용 기관 | 센터, 교육원(화면에서) | `organizations`, `org_id`, `is_training` | — | A2·R4·R5 |
| 가입 코드 | 참여 코드 | 표 `join_codes`, `POST /api/auth/signup` | Mã | A2·R5 |

- 교육생·강사는 교육용 기관(`organizations.is_training = true`) 화면에서만 씁니다. 둘을 함께 말할 땐 '작성자(교육생)', '관리자(강사)'.
- '요양보호사'는 누가 쓰는 앱인지 설명할 때(기획안·발표·AI 프롬프트·교재 출처)만 씁니다.
- 베트남어 '관리자'는 người quản lý 하나입니다. người phụ trách, nhân viên phụ trách(담당자)는 쓰지 않습니다.
- '담당자'는 쓰지 않습니다. 누가 맡은 일인지 드러나지 않는 중립적인 말이라 검토·승인하는 사람을 가리키기 어렵습니다(10/29 팀장·기획 담당). '담당 어르신', '담당 시작일'처럼 작성자와 어르신의 담당 연결을 말할 때의 '담당'은 그대로 씁니다.
