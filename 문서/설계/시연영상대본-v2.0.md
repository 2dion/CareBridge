## 1. 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 길이 | **약 4분 15초** (제한 2~5분) |
| 구성 | 오프닝 0:15 → 시나리오 1 2:25 → 시나리오 2 1:20 → 클로징 0:15 |
| AI 모드 | **실제 모드(배포본)**. 기대 결과는 `data/demo/voices.md` |
| 녹음 | 이미 있는 음성 2개만 씀. 시나리오 1은 `voice-3`(베트남어), 시나리오 2는 `voice-1`(한국어). 다른 기기로 틀어 W2에 들려줌. 새 음성 파일 필요 없음. **한 녹음에는 한 언어만** |
| 직접 입력할 것 | 1-4 "죽 반 안 되게 드셨어요.", 1-8 "동전 크기로 빨개요." 모두 **글로 입력** |
| 인물 | 모두 가상 인물. 작성자 '마이'(베트남 출신 요양보호사), 관리자 '박 사회복지사', 시설 어르신 김○○, 교육용 어르신 최○○ |
| 화면 | 작성자는 휴대폰, 관리자·강사는 PC 화면 녹화. 편집에서 이어 붙임 |
| 어투 | 내레이션은 '~합니다', 같은 문장을 자막으로도 씀 |

**이 영상으로 보여 줄 것 4가지**

1. 모국어로 한 번 말하면 법정 기록지 9개 항목의 한국어 초안이 나온다. (시나리오 1)
2. AI는 지어내지 않고 애매한 것은 '확인 필요'로 남기며, 관리자가 확인하지 않으면 승인이 잠긴다. (시나리오 1)
3. 관리자가 되돌린 이유를 작성자가 모국어로도 보고 고치며, 승인한 기록은 법정 서식으로 출력된다. (시나리오 1)
4. 교육원에서부터 쓰고, 교재 도우미로 한국어와 실무를 함께 배운다. (시나리오 2)

## 3. 촬영 준비와 편집 메모

**촬영 전**

- [ ] 데모 데이터 초기화(`supabase/demo-data.sql`). 김○○·최○○ 카드가 '작성 전'인지, 승인한 재가 기록(이○○)이 M3에 있는지 확인
- [ ] 휴대폰: 일반 기관 작성자 계정, 교육용 기관 교육생 계정. PC: 관리자 계정, 강사 계정(비밀번호는 백엔드 담당에게)
- [ ] `voice-3`·`voice-1`을 틀 기기 준비(데이터 담당 공유 폴더)
- [ ] `voice-3`을 스피커로 틀어 휴대폰 마이크로 받는 것 한 번 시험. 안 되면 조용한 곳에서 스피커를 휴대폰 가까이
- [ ] 1-7~1-9 되돌리기 흐름을 한 번 미리 해 보기: "동전 크기로 빨개요."를 넣은 뒤 불편감 표현이 어떻게 나오는지
- [ ] 휴대폰·PC 화면 녹화 켜기, 알림 끄기, 휴대폰 글자 크기 크게
- [ ] 화면에 실명·실제 어르신 사진이 없는지 확인(합성 사례·일러스트만, 원칙 9)
- [ ] 실제 모드는 코디세이 토큰을 씁니다. 음성 한 번에 약 36,000 토큰이라 시나리오마다 한 번에 끝내는 것을 목표로 합니다

**촬영 중**

- 시나리오마다 따로 찍어 편집에서 잇습니다. 휴대폰 컷과 PC 컷이 바뀔 때 "관리자 PC" / "작성자 휴대폰" 작은 자막을 붙입니다
- AI가 기대 결과와 다르게 나오면 다시 찍기 전에 토큰 한도를 먼저 확인합니다. 기대 결과는 `data/demo/voices.md`
- 음성 3·1의 기대: 식사·불편감 표현 '확인 필요' 2개, 특이사항은 "엉덩이 쪽 피부가 조금 붉어 보임." 한 줄(#205). 음성 3은 근거 문장이 베트남어 원문
- 1-8 뒤 불편감 표현이 '관찰'로 바뀌면 1-9의 [확인함]은 건너뛰고 바로 [승인]을 누릅니다. 내레이션은 그대로 둡니다
- 나오면 안 되는 것: 욕창·피부염 같은 진단 말, AI가 고른 섭취량, "오늘 기록은 여기까지입니다"가 특이사항에 들어감

**편집**

- 녹음 장면(1-2, 2-4)은 앞 5초만 소리를 내고 나머지는 빨리감기. 화면 구석에 "실제 녹음 52초"처럼 원래 길이를 적습니다(`voice-3` 약 52초, `voice-1` 약 61초)
- '정리 중' 기다리는 시간은 자르고 "AI 정리 중(실제 약 ○초)"로 표시합니다
- 주황 '확인 필요', 잠긴 [승인], 근거 문장 강조, 베트남어 사유 띠는 확대나 동그라미로 눈길을 모읍니다
- 내레이션은 한 사람 목소리로 녹음하고 같은 문장을 자막으로 씁니다
- 5분을 넘거나 길면 줄이는 순서: 1-12(제12호) → 1-10(AI 작업 기록) → 2-1. 도우미(2-2·2-3)는 끝까지 둡니다

## 5. v1에서 바뀐 것

- 시설 기록(시나리오 1)과 재가 되돌리기(시나리오 2)를 한 시나리오로 합침. 시설 김○○ 한 건에서 베트남어 말하기 → 되돌리기 → 승인 → 별지 제16호까지 이어짐(10/31 기획 담당)
- 녹음을 3개에서 2개로 줄임: 시나리오 1은 `voice-3`(베트남어), 교육용 시나리오는 `voice-1`(한국어). `voice-2`는 쓰지 않음
- 되돌리기는 불편감 표현에 "빨개진 부위의 크기를 적어 주세요."로 하고, 고치는 말 "동전 크기로 빨개요."는 글로 입력
- 별지 제12호는 승인한 재가 기록의 인쇄 화면으로만 짧게 보여 줌(넣을 수 있으면)
- 내레이션을 말하듯 자연스럽게 다듬음
- 버튼 이름: [맞아요] → [확인 완료], 식사 카드 '말로 보태기' → [내용 수정] (#215). '수정 요청 항목' 묶음(#199), 특이사항 기대(#205) 반영
- 길이 약 4분 40초 → 약 4분 15초
