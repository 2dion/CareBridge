2026-10-26 · @2dion (v1.1: 2026-10-18)

## 이 문서는 왜 있나

- **목적:** 외국인 돌봄 인력이 한국어 돌봄 기록을 직접 남기고, 기관이 그 기록을 믿고 승인할 수 있게 하는 서비스의 기준을 하나로 정한다.[3][2]
- **배경:** 외부 피드백에서 Agent 필수, 1주 MVP 뒤 테스트라는 조건이 나왔고, 승인 규칙·일정·담당이 문서마다 달랐다.[1]
- **근거:** 외부 피드백 검토 문서, 2dion 10/18 결정, 기획안 v1.0과 그 근거 자료(인터뷰·멘토링·회의).[1][2][3][12]
- **사유:** v1.0을 버리지 않고 바뀐 곳만 고쳐 v1.1로 올린다. 개발 문서 5개가 같은 말을 하게 하려면 기획안이 먼저 바뀌어야 한다.[2]

## 문제와 배경

**왜:** 누구의 어떤 어려움을 푸는지가 결정 1·2의 출발점이다.

**1. 돌봄 인력이 늙고 줄어, 외국인 인력을 늘리는 정책이 시작됐다.**
- 요양보호사 평균연령은 67.1세(2023년 12월)이고, 2027년 돌봄 인력이 약 7.9만 명 부족할 것으로 예상된다. 정부는 특정활동(E-7) '요양보호사' 직종을 2년 시범으로 만들고, 연 400명 범위에서 허용한다고 밝혔다(2024.7.8).[4]
- 2025년부터 유학(D-2)·구직(D-10) 비자 외국인도 요양보호사 교육(320시간)을 받을 수 있다. 자격을 따고 노인의료복지시설에 취업하면 E-7 비자를 받을 수 있고, 한국어 요건은 TOPIK 3급 또는 사회통합프로그램(KIIP) 3급 이상이다.[5]
- 지금 현장에서 일하는 외국인 요양보호사·돌봄 보조 인력의 수는 ⚠️ 통계 출처 확인 필요.
- 멘토도 같은 흐름을 짚었다. 요양보호사는 고령화·퇴직으로 줄고 그 자리를 외국인이 채우는데, 현장에는 이들을 도울 준비가 없다.[8] 식사 보조·씻기기 같은 직접 돌봄은 외국인 보조 인력이 많이 하고, 이들이 어르신 상태를 더 잘 안다.[9]

**2. 말은 통해도 한국어 기록 문장은 어렵다.**
- 외국인요양보호사교육원 교육원장(10/15, QA 담당 인터뷰): 가장 큰 벽은 한국어, 특히 장기요양 용어다. 번역기를 켜고 수업을 듣는 학생도 있다. 기록은 육하원칙·객관적·구체적으로 써야 한다("적게 드심"이 아니라 "세 숟갈 드심"). 기록은 요양보호사 본인 책임이고 보호자도 읽을 수 있어야 한다.[6]
- 간호사 인터뷰(10/12, 데이터 담당): 요양보호사는 식사량·배설·피부·어르신 말 같은 관찰 사실은 기록할 수 있지만, 진단명이나 정상/비정상 판단은 쓸 수 없다. 핵심 관찰은 식사·배설·피부다.[7]
- 멘토가 정리한 문제: ① 수급자 이름·돌봄 용어를 이해하기 어렵다 ② 무엇을 기록할지 판단하기 어렵다 ③ 한국어 문장으로 쓰는 데 시간이 오래 걸린다 ④ 관리자와 소통하려면 기록이 필요하다.[8]

**3. 그래서 케어브릿지는** 기록 문장 쓰기를 돕되, 판단은 사람(작성자와 담당자)이 하게 만든다. 공단 앱 같은 기존 시스템은 대체하지 않는다.[37]

## 한 줄 정의

**왜:** 팀과 심사자가 같은 그림을 보게 한다(결정 1·2).

**외국인 요양보호사가 음성 메모 하나로 한국어 기록 초안을 만들고, 담당자가 검토·승인하는 서비스.**[19] 화면은 한국어가 위, 모국어가 아래이고, 최종 기록은 항상 한국어입니다.[19]

## 기록 검토 준비 Agent

**왜:** 결정 17의 흐름과 도구를 개발 전 팀이 같은 말로 이해하게 한다. 자세한 입출력은 AI 규칙 v1.1과 데이터 구조 v1.1 '공통 계약'에 있다.[23][33]

**흐름:** 받아쓰기 끝 → 서버가 Agent 시작 → Claude가 도구를 골라 부름 → 서버가 도구를 실행해 결과를 돌려줌 → … → 초안 반환으로 끝.[2]

| 도구 | 하는 일 | 입력 → 출력 |
| --- | --- | --- |
| ① 서식 기준 조회 get_form_spec | 급여 종류로 별지 제16호(시설) 또는 제12호(재가)의 칸·선택지·작성 기준을 가져옴 | care_type → 칸 목록, 선택지, verified 값 |
| ② 용어 검색 search_terms | 사투리·일상 표현을 교재 공식 용어와 고정 번역으로 찾음. 못 찾으면 빈 결과 | 표현 → 후보 용어, 베트남어 고정 번역, 교재 장·쪽 |
| ③ 기록 검증 validate_draft | 코드 검사: 9개 항목·형식, 근거가 원문에 있는지, 관찰인데 근거 없음, 언급 없음인데 내용 있음, 재가 제공시간 합 ≤ 방문 시간, 실명 | 초안 → 통과/문제 목록 |
| ④ 초안 반환 submit_draft | 9개 항목과 서식 칸 값을 저장하고 끝냄. 저장 직전 검증을 한 번 더, 남은 문제 항목은 '확인 필요'로 낮춤 | 초안 → 저장 |

**멈춤 규칙:** 최대 4번(Claude 응답 4번). 같은 도구에 같은 입력은 한 번만(서버가 막고 앞 결과를 돌려줌). 4번 안에 초안 반환이 없으면 서버가 마지막 초안을 검증해 저장하고, 못 정한 항목은 모두 '확인 필요' + "자동 정리 중단". 도구 실패는 한 번 다시, 또 실패하면 v1.0 예외 처리와 같다.[2]

**비용·지연:** Claude 호출이 기록당 1번 → 최대 4번이 된다. 뒷배경 처리라 작성자는 W2(음성 메모) 다음 W3(기록 초안 확인)에서 '정리 중'을 본다. 건당 시간·비용은 품질 확인 표에서 함께 잰다.[1]

## 메뉴와 화면

**왜:** 결정 2·8의 흐름을 화면 단위로 고정한다. 화면별 내용은 화면 설계 v1.1에 있다.[31]

- **작성자 하단 탭 4개:** 오늘 / 기록함 / 도우미 / 내 정보. 화면은 W0(사용 안내), W1(오늘), W2(음성 메모), W3(기록 초안 확인), W4(기록함), W5(내 정보), W6(도우미).
- **담당자 왼쪽 메뉴 4개:** 검토 대기 / 승인한 기록 / 어르신·작성자 / 설정. 화면은 R1(검토 대기), R2(검토 화면), R3(승인한 기록), R4(어르신·작성자, 설정).
- **흐름:** W1(오늘) → W2(음성 메모) → W3(기록 초안 확인, Agent가 끝나면 초안 표시) → [담당자에게 보내기] → R1(검토 대기) → R2(검토 화면, '확인 필요'를 모두 처리해야 [승인]) → 승인하면 R3(승인한 기록), 되돌리면 W4(기록함)에 '되돌아온 기록' → W3(기록 초안 확인).
- **교육용 기관:** 강사가 담당자와 같은 흐름으로 검토한다. 되돌리면 W4(기록함)에 '되돌아온 기록', 승인하면 '연습용' 표시가 붙은 승인 기록이 된다(10/25).[42]

"제공 지원" 카드 안에는 하위 칩(세면·목욕·체위변경·배설·이동·말벗)을 둡니다. 재가는 영역별 제공시간(분)과 대변·소변 실수 횟수(2칸)를, 시설은 소변·대변 총 횟수를 함께 받습니다.[40][41] 말하지 않은 시간은 추정하지 않고 "언급 없음"으로 둡니다. 제공시간 합이 방문 시간을 넘는지는 코드(기록 검증)가 봅니다.[25][23]

**표현 충돌 규칙**은 v0.5와 같습니다. 서식 칸 이름 → 데모용 용어 목록(교재 본문 용어) → 용어집 순서로 근거를 쓰고, 관찰을 진단명으로 올리지 않으며("욕창"이 아니라 "엉덩이 부위 발적 관찰"), 뜻이 둘 이상이면 채우지 않고 "확인 필요"로 둡니다.[11][23]

## 시연

**왜:** 심사자에게 결정 2·8·12·17이 실제로 돌아가는 모습을 보여 준다.

시연은 세 가지입니다. ① 시설 기록 한 건(별지 제16호, 'AI 작업 기록'과 승인 차단 포함), ② 재가 방문요양과 되돌리기(별지 제12호), ③ 교육용 기관 연습(강사 되돌리기 → 고쳐 보냄 → 승인, '연습용' 표시)과 도우미. 단계별 내용은 시연 시나리오와 일정 v1.1에 있습니다.[34]

베트남어는 팀 자체 검증(역번역+용어 목록)만 했다는 한계를 발표에 적습니다. 교육원을 통해 베트남 교육생 1~2명에게 화면을 보여 줄 수 있으면 테스트 기간에 넣습니다(선택).[1]

## 실서비스 전환 시 확인할 것

**왜:** MVP 작업은 아니지만, 심사에서 "실제로 쓸 수 있나"를 물으면 답할 목록이다.[1]

- **업무 효과:** 교육용과 현장용 지표를 나눈다. 교육용 = 기록 원칙 위반·누락 감소, 용어 사용 증가. 현장용 = 기록 시간, 담당자 수정 횟수, '확인 필요' 비율.
- **도입 주체:** 누가 비용을 내고 들이나(교육기관, 요양기관). 교육기관에 먼저 적용하는 순서는 유지한다.[8]
- **데이터 보관·삭제:** 음성은 글자로 바뀌면 지운다. 기록·이력의 보관 기간과 삭제 절차는 확인 필요.
- **운영 책임:** 승인 책임은 담당자에게 있다. AI 오류 신고와 대응, 장애 시 처리는 확인 필요.
- **교재·서식 자료 이용:** 교재 텍스트·이미지와 별지 서식을 서비스에 쓰는 조건을 확인한다.
- **번역 검증:** 베트남어는 지금 팀 자체 검증뿐이다. 실서비스 전에는 원어민 검수가 필요하다.[1]
