# 회원가입(A2)과 내 정보(W5)에서 작성자가 모국어를 고른다

- **상태:** 유효
- **정한 날·사람:** 2026-11-05 · 2dion
- **관련:** 결정 [병기모드우선](2026-10-25-병기모드우선.md) 3번(A2·W5 부분을 대체), 결정 [로그인가입](2026-10-25-로그인가입.md), 결정 [용어번역표](2026-11-03-용어번역표.md) 4번(`records.native_lang`), 결정 [모국어추가](2026-11-05-모국어추가.md)(이슈 #308, 어떤 언어를 더할지), [다국어 확장 구조 v2.0.0](../설계/다국어확장-v2.0.0.md) '목표 구조 5', 화면 설계 v2.2.2 A2 ⑥·W5, 데이터 구조 v2.3.4 `POST /api/auth/signup`·profiles 권한

## 배경

- 10/25 병기모드우선 결정으로 W0·W5·A2의 언어 선택을 숨겼고, 가입 화면은 작성자·교육생에게 `native_lang: "vi"`를 고정으로 보냅니다.[1]
- 다국어 확장 단계 0~2로 언어 목록(`web/lib/i18n/languages.ts`)·화면 번역 파일·용어 번역 표가 준비됐고, 기획 담당이 더할 언어(중국어 간체·몽골어·영어)를 제안했습니다.[2][3]
- 언어를 더해도 작성자가 고를 곳이 없으면 쓸 수 없습니다. 지금 코디세이 DB의 작성자 계정은 모두 `vi` 아니면 `ko`입니다.[4]

## 결정

1. **A2(회원가입):** ⑥ 모국어 칸을 다시 보입니다. 목록은 언어 목록에서 켜진 언어만 보이고, 기본은 지금처럼 `vi`(한국어+베트남어)입니다. 고른 값을 `POST /api/auth/signup`의 `native_lang`으로 보냅니다. 관리자 코드면 지금처럼 서버가 `ko`로 저장합니다.
2. **A2 화면의 번역 줄:** 로그인 전에는 모국어를 몰라 지금처럼 베트남어 줄로 시작하고, ⑥에서 고르면 그 화면의 번역 줄이 고른 언어로 바뀝니다. 고른 언어에 번역 파일 키가 없으면 그 줄은 숨깁니다.
3. **W5(내 정보):** '언어' 줄을 다시 보입니다. 누르면 같은 목록에서 고르고, 고르면 `profiles.native_lang`을 바꿉니다. 이미 작성자가 자기 행의 `native_lang`을 고칠 권한이 있어(RLS·컬럼 권한) 새 API는 만들지 않습니다.
4. **목록에 '한국어'도 둡니다:** `ko`는 번역 없음(한국어만)입니다. 작성자가 "보조 바퀴를 떼는" 선택을 W5에서 할 수 있습니다(10/22 멘토링 결정 8).
5. **언어를 바꾼 뒤 옛 기록:** 기록마다 만든 때 언어(`records.native_lang`)가 고정이라 그대로 둡니다. 지금 언어와 다른 기록은 번역 줄을 숨기고 한국어만 보입니다(용어번역표 결정 4번, 다국어 확장 '목표 구조 2').
6. **W0(사용 안내)의 언어 선택은 그대로 추후 적용입니다.** 고를 곳은 A2·W5 두 곳입니다.
7. **바뀌지 않는 것:** 최종 기록은 한국어, 화면 틀은 한국어, 듣기(TTS)는 한국어만, 공통 계약의 API·값 목록은 이 결정으로 바뀌지 않습니다(값 목록은 언어를 더하는 결정에서 바뀜).

## 검토한 대안

- **대안 A: 가입 때만 고름:** 화면이 하나 / 잘못 고르거나 한국어가 늘어 번역을 끄고 싶을 때 바꿀 곳이 없음. 버림
- **대안 B: W5에서만 고름:** 가입 화면이 단순 / 가입 직후 W0부터 엉뚱한 언어 번역이 보임. 버림
- **대안 C: W0 첫 장에서도 고름:** 첫 실행 때 한 번 더 확인 / 가입에서 막 고른 것을 다시 물음. 버림(추후 적용 유지)
- **채택:** A2에서 처음 고르고, W5에서 언제든 바꿈

## 사유

가입에서 고르면 첫 화면부터 맞는 번역이 보이고, W5에서 바꿀 수 있으면 잘못 고른 것과 한국어가 는 경우를 모두 작성자가 스스로 고칩니다. 저장 칸과 권한은 이미 있어 화면 일만 늘어납니다.

## 영향

- **화면(FE):** `web/app/(auth)/signup/page.tsx`(⑥ 모국어 칸, `native_lang` 고정값 빼기, 고른 언어로 번역 줄), `web/app/(worker)/me/page.tsx`(언어 줄과 고르는 화면), 목록은 `languages.ts`에서만 읽음
- **서버(BE):** 바꿀 것 없음(가입 API가 이미 `native_lang`을 검사). 언어 목록에 '켜진 언어' 표시(`enabled`)를 더하는 일은 모국어추가 결정과 함께
- **화면 설계(기획):** A2 ⑥·W5 '언어'의 'MVP는 숨김' 문장, 공통 규칙 '병기 모드 하나' 줄, 추후 적용 표의 W5·A2 줄을 고침(W0는 그대로)
- **QA:** 가입 때 고른 언어로 W0~W6 번역 줄 확인, W5에서 `ko`로 바꾸면 번역 줄이 모두 숨는지, 바꾼 뒤 옛 기록은 한국어만 보이는지
- **결정 기록:** 병기모드우선 상태를 '일부 대체됨'으로
