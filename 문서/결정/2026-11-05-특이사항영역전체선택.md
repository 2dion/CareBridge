# 제16호 '특이사항을 넣을 영역'은 여러 개를 고르게 하고, 4개 모두 선택을 기본으로 한다

- **상태:** 유효
- **정한 날·사람:** 2026-11-05 · 팀장 요청, 백엔드 담당 구현 (이슈 #321)
- **관련:** 결정 [기간인쇄](2026-11-03-기간인쇄.md) 8번 ‘제16호 특이사항’(대체), 결정 [인쇄이어쓰기쪽](2026-11-05-인쇄이어쓰기쪽.md) 5번(‘notes 영역을 관리자가 고르는 것’ 부분 대체), 화면 설계 v2.3.1 M3·M3 · 기간 인쇄, 이슈 #321

## 배경

- 제16호 기록에 자유 서술 특이사항(`notes`)이 있으면 관리자가 4개 영역(신체활동지원 / 인지관리 및 의사소통 / 건강 및 간호관리 / 기능회복훈련) 중 **하나만** 골랐고, 고르기 전에는 [PDF 만들기]가 꺼져 있었습니다.
- 특이사항 한 줄이 여러 영역에 걸치는 경우가 많고, 날마다 고르는 기간 인쇄에서는 손이 많이 갔습니다.
- 팀장 요청(11/05): 전체 선택이 기본이어야 합니다.

## 결정

1. **선택 방식:** 영역을 하나 고르는 선택 칸 대신 영역 4개의 **체크(여러 개)**를 둡니다. 기록 1건 인쇄와 기간 인쇄(날짜마다) 모두 같습니다.
2. **기본값:** 처음 열면 4개 모두 체크되어 있습니다. 관리자가 필요 없는 영역만 끕니다.
3. **PDF:** 체크한 영역마다 그날 열의 특이사항 칸에 같은 `notes`를 넣습니다. 칸을 넘친 글은 지금처럼 이어쓰기 쪽에 모읍니다(결정 인쇄이어쓰기쪽).
4. **막기:** 평소(기본값)에는 막지 않습니다. 한 날이라도 4개를 모두 끄면 [PDF 만들기]를 끄고 ‘특이사항 영역을 하나 이상 골라 주세요’를 보입니다. 서버·PDF 코드도 영역이 빈 목록이면 오류로 멈춥니다.
5. **저장하지 않습니다.** 영역 선택은 화면 상태일 뿐입니다.
6. **범위:** 제16호(시설)만. 제12호(재가)는 특이사항 칸이 하나라 해당 없습니다.
7. **바뀌지 않는 것:** 칸 좌표, 식사·수면·불편감·복약 글을 어느 칸에 넣는지, 복약 관찰을 간호 행위로 바꾸지 않는 것.

## 검토한 대안

- **대안 A: 하나만 고르기(기존):** 영역을 정확히 짚음 / 여러 영역에 걸친 글에 손이 많이 가고 기본값이 비어 매번 골라야 함. 버림
- **대안 B: 여러 개 고르되 기본은 비움:** 의도하지 않은 영역에 안 들어감 / 팀장 요청(전체 선택이 기본)과 다르고 매번 눌러야 함. 버림
- **채택:** 체크 4개, 기본 전체

## 사유

- 기본이 전체이면 대부분의 날은 손을 대지 않고 [PDF 만들기]를 누를 수 있습니다.
- 같은 글이 여러 칸에 들어가도 글자 손실은 없고, 필요 없는 칸만 관리자가 끕니다.
