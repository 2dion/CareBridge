# 몽골어는 켜되 받아쓰기 확인을 통과할 때까지 글로 기록만 안내한다 (sttChecked가 꺼진 언어의 W2·W3)

- **상태:** 유효 (백엔드 담당 제안·구현, 팀장 확인 요청)
- **정한 날·사람:** 2026-11-07 · 백엔드 담당 (이슈 #386, 부모 #315·#308)
- **관련:** 결정 [모국어추가](2026-11-05-모국어추가.md) 3번, 결정 [녹음한언어](2026-10-30-녹음한언어.md) 대안 C, 다국어 확장 구조 v2.0.0 '6. 받아쓰기·글꼴', 화면 설계 v2.3.4 W2·W3, `web/lib/i18n/languages.ts`

## 배경

- #315에서 몽골어는 역번역·글꼴·언어 선택을 통과했지만, 합성 음성 받아쓰기는 실패했습니다. Groq `whisper-large-v3`(언어 자동 인식)가 몽골어를 카자흐어 글자로 받아써 대본 일치율이 0.5%였습니다.
- 공개 자료에서 이 모델의 몽골어 단어 오류율은 80%대입니다(#386 댓글). 합성 음성 탓보다 모델 한계로 보여, 사람 목소리로 다시 확인해도 통과할 가능성이 낮습니다.
- 다국어 확장 구조 v2.0.0은 "받아쓰기를 통과하기 전에는 그 언어로 '쓰기'만 안내"한다고 적었지만, `sttChecked`를 실제로 쓰는 코드는 없었습니다.

## 결정

1. **몽골어(`mn`)를 켭니다:** `enabled: true`, `sttChecked: false`. 가입(A2)·언어 선택(W5)에 보이고, 글로 기록·번역·도우미는 다른 언어와 같습니다.
2. **`sttChecked`가 꺼진 언어의 작성자에게는 말로 기록을 열지 않습니다.** W2(기록 시작)에서 [음성으로 기록] 카드 대신 "이 언어는 아직 말로 기록을 지원하지 않아요. 글로 기록해 주세요." 안내(한국어 + 모국어 병기)를 보이고, W3 항목 보태기의 [말로 추가]·[다시 말하기] 버튼을 숨깁니다. 판단은 `isSttChecked(작성자 모국어)` 한 곳에서 합니다.
3. **서버는 막지 않습니다.** `upload-url`·`/audio`는 그대로입니다. 받아쓰기가 틀려도 Agent는 지어내지 않고 '확인 필요'로 두므로(#315 mn 기록) 기록이 잘못 저장될 위험은 없고, 공통 계약(오류 키)을 늘리지 않기 위해서입니다.
4. **받아쓰기 확인을 통과하면** `sttChecked: true`로 바꾸기만 하면 말로 기록이 열립니다. 통과 기준은 모국어추가 결정 3번과 같습니다.
5. **바뀌지 않는 것:** 받아쓰기 모델·`language` 미지정(녹음한언어 결정), 한 녹음 한 언어, 다른 네 언어의 동작.

## 검토한 대안

- **대안 A: `language=mn` 힌트를 Groq에 보내기(녹음한언어 대안 C):** 글자가 몽골어 키릴로 나올 수 있음 / 모델의 몽골어 오류율이 80%대라 효과가 불확실하고, 한국어로 말한 녹음이 깨질 위험. 버림(사람 목소리·키 실험 결과가 나오면 다시 봄)
- **대안 B: 몽골어를 끈 채 두기:** 변경 없음 / 역번역·화면이 통과한 언어를 받아쓰기 하나 때문에 전부 막음. 몽골 국적 요양보호사는 베트남 다음으로 많음(모국어추가 결정). 버림
- **대안 C: 받아쓰기 모델 바꾸기:** 몽골어 성능이 나은 모델 / 코디세이 범위 밖. 기록만
- **채택:** 켜되 말로 기록만 닫기(화면), `sttChecked` 한 칸으로 열고 닫음

## 사유

글로 기록·번역·도우미는 지금 바로 쓸 수 있고, 안 되는 것(받아쓰기)만 닫는 가장 작은 변경입니다. `sttChecked`의 뜻("받아쓰기 품질 확인을 마쳤는지")을 코드가 실제로 쓰게 됩니다.

## 영향

- **BE:** `languages.ts`(`mn` enabled, `isSttChecked`), 테스트(`languages`·`language-selection`·`signup`·`worker-pages`)
- **FE:** W2 시작 화면 음성 카드 → 안내, W3 항목 보태기 음성 버튼 숨김, 문구 `w2.start.voiceUnavailable`(vi·zh·mn·en)
- **문서:** 화면 설계 v2.3.4 W2·W3 예외, 데이터 구조 v2.3.11 `native_lang` 고를 수 있는 값
- **QA:** #386 끝난 기준 1번(사람 목소리 확인)은 남습니다. 통과하면 `sttChecked`만 켭니다
