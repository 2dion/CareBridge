# 관리자 가입 코드는 공개하지 않고, 노출되면 바로 바꾼다

- **상태:** 유효
- **정한 날·사람:** 2026-11-03 · JiNS03
- **관련:** 이슈 #256, 결정 [2026-10-25-로그인가입](2026-10-25-로그인가입.md), 데이터 구조 v2.1.1 join_codes

## 배경

가입은 가입 코드가 기관과 역할을 정하고, 이메일 확인은 하지 않습니다. 관리자 코드가 새면 누구나 그 기관 관리자가 될 수 있습니다.

## 결정

1. 관리자(강사) 가입 코드는 저장소·이슈·시연 영상·발표 자료·채팅에 적지 않습니다. 작성자 코드도 공개 자료에는 적지 않습니다.
2. 관리자 코드가 노출됐거나 의심되면 그 코드를 `active = false`로 바꾸고 새 코드를 만듭니다.
3. 시연·심사가 끝나면 시연에 쓴 가입 코드를 모두 바꿉니다.
4. 가입 흐름(코드 확인, 이메일 확인 없음)과 API는 바꾸지 않습니다. 직접 가입(Supabase Auth `signUp`)은 막고 `/api/auth/signup`만 씁니다.

## 검토한 대안

- 관리자 코드 1회용: 노출 위험이 가장 작음 / 새 관리자마다 코드를 만들 화면이 없어 DB에서 직접 만들어야 함
- 이메일 확인 켜기: 남의 이메일 가입을 막음 / 시험 계정·시연 흐름이 바뀌고 메일 발송 설정이 필요함

## 사유

11/08 전에 가입 흐름을 바꾸지 않고 노출 위험을 줄이는 운영 규칙입니다. 1회용 코드와 이메일 확인은 제출 뒤 다시 검토합니다.

## 영향

- 팀장: 코디세이 Supabase Auth에서 직접 가입 끄기(공모전 환경은 변경하지 않음), 시연 뒤 코드 교체
- 저장소: `supabase/config.toml` 직접 가입 끄기, 비밀번호 최소 8자
