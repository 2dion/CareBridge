# W1 종 버튼을 빼고, R1에 다시 보낸 기록 아이콘과 검토 대기 숫자를 둔다

- **상태:** 유효
- **정한 날·사람:** 2026-10-28 · EUN
- **관련:** 화면 설계 v1.3 W1·W4·R1, 화면 문구 v1.0 R1, 못쓴기록 결정 6(알림은 앱 안에서만)

## 배경

알림 항목을 정리하면서 지금 앱(main, PR #67)과 화면 설계를 맞춰 봤습니다.[1] 세 가지가 어긋났습니다.

- W1(오늘) 오른쪽 위 종 버튼은 누르면 기록함 ‘수정 필요’ 탭으로 갑니다. 바로 아래 ‘수정 필요’ 띠와 하는 일이 같고, 점·숫자도 없으며, 화면 설계에도 없습니다.
- 담당자 왼쪽 메뉴 ‘검토 대기’ 옆 숫자는 앱에만 있고 화면 설계에는 없습니다.
- 되돌린 기록을 작성자가 고쳐 다시 보내면 R1(검토 대기)에서 새 기록과 똑같이 보여, 담당자가 구별하지 못합니다.

## 결정

1. **W1 종 버튼을 뺍니다.** 수정 필요 기록은 W1 주황 띠와 W4(기록함) ‘수정 필요’ 탭으로 알립니다. 푸시·알림 목록이 생기는 추후 적용 때 다시 봅니다.
2. **W4 탭 숫자는 ‘작성 전’ 탭에만 둡니다.** 하단 탭 ‘기록함’ 아이콘에는 수정 필요 숫자를 붙이지 않습니다. 기록함은 전체 기록을 보는 곳이고, 할 일은 W1 띠가 알립니다.
3. **R1 메뉴 ‘검토 대기’ 숫자를 둡니다.** 값은 R1 표와 같은 보낸 기록(`submitted`) 수이고, 0이면 숨깁니다.
4. **R1 다시 보낸 기록에 ↻ 아이콘을 둡니다.** 어르신 이름 옆에 글자 대신 아이콘을 두고, 마우스를 올리면 “다시 보낸 기록”이 보입니다. 이런 기록이 표에 있으면 표 위에 아이콘 뜻을 한 줄 둡니다. 되돌린 이력(`record_events`의 `returned`)이 있는 보낸 기록이면 붙입니다.

## 검토한 대안

- **종 버튼에 수정 필요 숫자 붙이기:** 띠와 숫자가 두 번 보이고, 종은 ‘알림 목록’을 기대하게 하는데 목록이 없습니다.
- **기록함 하단 탭에 숫자 붙이기:** 다른 탭에서도 보이는 장점이 있지만, 기록함을 할 일 목록처럼 보이게 합니다(EUN 10/28).
- **‘다시 보냄’ 글자 칩:** 뜻은 바로 보이지만 표 한 줄이 길어집니다. 아이콘으로 직관적으로 보이게 하는 쪽을 골랐습니다(EUN 10/28, 2dion 10/16 “글을 줄이고 아이콘으로”).[2]

## 사유

같은 일을 하는 표시를 줄이고, 담당자가 손이 더 갈 기록(다시 보낸 기록)을 바로 알아보게 합니다. 새 표·API·상태 값은 없습니다.

## 영향

- **화면 설계 v1.3:** W1·W4·R1에 한 줄씩. 문장만 더해 버전 유지.
- **화면 문구 v1.0:** R1 메뉴 숫자, 아이콘 이름·설명 줄.
- **화면(프론트엔드 담당):** W1 종 버튼과 스타일 삭제, R1 아이콘·설명 줄.
- **서버(백엔드 담당):** 바뀔 것 없음. 실제 R1은 `record_events`에서 `returned`가 있는지 함께 읽어야 합니다.
- **테스트(QA 담당):** 다시 보낸 기록 판정 테스트 1개.
- **일정:** 기능 마감(10/23) 뒤 화면 정리라 팀장 확인을 받습니다.
