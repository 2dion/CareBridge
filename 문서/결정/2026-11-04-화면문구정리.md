# 작성자·관리자 동작은 '수정' 하나로 부르고, 용어집과 어긋난 화면 문구 7개를 정한다

- **상태:** 유효
- **정한 날·사람:** 2026-11-04 · 기획 담당
- **관련:** 이슈 #232 B, 용어집 v2.0.1, 화면 설계 v2.2.2 W2, 결정 [2026-10-31-작성자버튼](2026-10-31-작성자버튼.md), [2026-10-29-용어통일](2026-10-29-용어통일.md), [2026-10-28-기한지난빈기록](2026-10-28-기한지난빈기록.md)

## 배경

10/31 점검(이슈 #232)에서 화면 글자와 용어집이 어긋난 곳 가운데, 기획이 먼저 정해야 FE가 맞출 수 있는 것이 7개 나왔습니다. 그중 '수정(관리자) / 고치기(작성자)'는 작성자버튼 결정에서 작성자 버튼을 [내용 수정]으로 바꾼 뒤에도 용어집에 남아, 같은 동작을 버튼은 '수정', W3 배지는 '고침'으로 부르고 있었습니다.[1]

## 결정

| # | 화면 | 정한 것 | 베트남어 |
| --- | --- | --- | --- |
| 1 | W3·M2·M3 | 작성자·관리자 동작 모두 '수정'. W3 배지 '고침' → '수정 완료', 확인 완료 카드의 [다시 고치기] → [다시 수정](#232 A와 겹침), M3 이력 '… 고침' → '… 수정'. '고치기·고침'은 쓰지 않는 이름 | 배지는 한국어만(옆 '확인 완료'와 같음) |
| 2 | W3 | '내가 한 말'은 그대로. 근거(`evidence`)의 작성자 화면 이름으로 용어집에 적음 | 작성자 자신의 말이라 병기 안 함 |
| 3 | M0 | [기록 없음으로 정리]는 그대로. 결과 상태 '기록 없음 처리'를 만드는 관리자 버튼으로 용어집 '동작' 표에 적음 | 관리자 화면이라 한국어만 |
| 4 | W2·W0 | [음성으로 기록]은 그대로. W0 사용 안내 1장 '말로 기록' → '음성으로 기록', 3장과 겹치는 '쉽게 확인' → '도우미에게 질문'. 2장 '음성으로 입력'은 1장과 겹치므로 '편하게 말하기'로 | 1장 Ghi bằng giọng nói(W2 버튼과 같음) · Hỏi trợ lý chăm sóc(용어집 '도우미'), 2장 Nhập bằng giọng nói → Nói tự nhiên |
| 5 | W2 · 녹음 | 마이크 권한·녹음 못 하는 브라우저 안내의 [다시 시도]는 예외로 씀. 권한을 다시 묻는 버튼이고 버릴 녹음이 없음 | Thử lại(W3·W6와 같음) |
| 6 | W 전부 | 작성자 베트남어는 người ghi chép. 함께 말할 땐 người ghi chép (học viên) | 원어민 검수 전 |
| 7 | W4·W5 | 승인 베트남어는 용어집대로 duyệt | W4 'đã phê duyệt bản ghi' → 'đã xem xét và duyệt bản ghi'(한국어 '검토하고 승인했어요'에 맞춤), W5 'phê duyệt' → 'duyệt' |

동작, API, 표, 상태 값은 바뀌지 않습니다. 화면 글자와 문서만 바꿉니다.

## 검토한 대안

- 1번 배지 '수정함': 더 짧음 / 옆 배지 '확인 완료'와 꼴이 달라짐
- 1번 용어집대로 버튼을 [내용 고치기]로 되돌림: 용어집은 그대로 / 10/31 작성자버튼 결정을 뒤집음
- 2번 '원문'으로 바꿈: 용어집 단어 / 원문은 받아쓴 글 전체(`transcript`)라 항목 근거 한두 문장과 헷갈림
- 4번 W0 2장 '타이핑 없이': [글로 쓰기]도 있어 오해 / '모국어로 말하기': 큰 장점이지만 첫 안내에서 모국어를 앞세우면 한국어 중심(기획안 결정 5)과 어긋남
- 3번 버튼을 [기록 없음 처리]로 바꿈: 상태 이름과 같음 / 결정 기록·화면 설계·FE 세 곳을 고쳐야 하고 얻는 것이 적음
- 5번 [마이크 다시 켜기] 같은 새 이름: 뜻이 더 분명함 / 버튼이 길어지고 베트남어를 새로 정해야 함
- 6번 nhân viên chăm sóc: 현장에서 익숙함 / 직업 이름이라 앱 안에서 '요양보호사'를 쓰지 않는 규칙과 어긋남

## 사유

같은 동작은 한 이름으로 부르고(작성자버튼 결정과 같은 기준), 이미 화면 설계·결정 기록이 정해 둔 이름은 바꾸지 않고 용어집에 적어 어긋남만 없앱니다. 베트남어는 같은 화면의 다른 글자(W2 버튼, W4 배지 'Đã duyệt')와 같은 말로 맞춥니다.
