# 도우미 답 언어의 옛 행은 작성자 프로필 언어로 채우고, 번역이 빈 답은 한국어 작성자에게만 재사용한다

- **상태:** 유효 ([도우미답언어](2026-11-06-도우미답언어.md) 2번 일부 대체)
- **정한 날·사람:** 2026-11-07 · 백엔드 담당 (이슈 #394 3번, 검토 세션 지적)
- **관련:** 결정 [도우미답언어](2026-11-06-도우미답언어.md) 2·6번, 결정 [도우미답재사용](2026-11-03-도우미답재사용.md), 데이터 구조 v2.3.11 `helper_messages`·`find_helper_answer`

## 배경

- 11/06 결정 2번은 옛 행의 `native_lang`을 "`answer_native`가 빈 행은 `ko`, 나머지는 `vi`"로 채웠습니다.
- 그런데 Mock이거나 번역이 실패해 `answer_native`가 빈 베트남어 작성자의 옛 답도 한국어 답으로 분류돼, 같은 질문 재사용(`find_helper_answer`, `native_lang`이 같은 답만)에서 빠집니다. 토큰을 조금 더 쓰는 문제이고 사용자에게 틀린 글이 보이는 문제는 아닙니다.

## 결정

1. **옛 행 다시 채우기:** `answer_native = ''`이고 `native_lang = 'ko'`인 행 중 작성자 프로필 언어가 `ko`가 아닌 행은 **작성자 프로필 언어**로 바꿉니다. 그 밖의 행은 그대로입니다. `native_lang`은 만든 뒤 바꾸지 못하는 칸이라 마이그레이션 안에서만 트리거를 잠시 끕니다.
2. **재사용 조건 추가:** `find_helper_answer`는 번역이 빈 답(`answer_native = ''`)을 한국어 작성자(`native_lang = 'ko'`)에게만 돌려줍니다. 모국어 작성자에게 번역 없는 답을 재사용하지 않습니다.
3. **바뀌지 않는 것:** 새 행의 언어는 서버가 보내고 DB가 빈 값을 채우는 규칙(11/06 결정 1번), 응답 모양, 권한.

## 검토한 대안

- **그대로 두기:** 변경 없음 / 베트남어 작성자의 옛 답이 재사용되지 않아 토큰을 더 씀. 버림
- **빈 번역을 지금 번역해 채우기:** 재사용률이 높아짐 / 옛 답마다 토큰을 쓰고, 번역이 틀리면 저장된 답과 어긋남. 버림
- **채택:** 언어만 프로필 기준으로 고치고, 빈 번역 답은 재사용에서만 빼기

## 사유

언어 칸은 "답을 만든 때 작성자 언어"가 뜻이라 프로필 언어가 더 맞고, 빈 번역은 재사용 때만 피하면 모국어 작성자에게 번역 없는 답이 가지 않습니다.
