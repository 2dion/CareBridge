# W4 [이 날 기록 없음]을 [기록 건너뛰기]로 바꾸고, 화면 문구 7개를 맞춘다

- **상태:** 유효
- **정한 날·사람:** 2026-11-05 · 기획 담당
- **관련:** 용어집 v2.0.5(`no_care_days` 줄), 화면 설계 v2.3.2 A1·A2·W4, 결정 [2026-10-25-못쓴기록](2026-10-25-못쓴기록.md), [2026-11-04-화면문구정리](2026-11-04-화면문구정리.md)

## 배경

11/05 화면 문장의 말투(해요체·합쇼체·개조식)를 화면별로 점검했습니다. 말투 규칙을 새로 정하지는 않고 그대로 두되, 한 화면 안에서 말투가 섞이거나 뜻이 흐린 문구만 고르기로 했습니다.

W4(기록) 작성 전 카드의 [이 날 기록 없음]은 버튼인데 상태 설명처럼 읽혔습니다. 누르면 열리는 창의 확인 버튼은 [기록 없음으로 처리]라 이름이 둘로 갈렸습니다.

## 결정

| # | 화면 | 정한 것 | 베트남어 |
| --- | --- | --- | --- |
| 1 | W4 작성 전 카드 | [이 날 기록 없음] → **[기록 건너뛰기]**. 옆 [지금 쓰기]는 그대로 | Bỏ qua ghi chép |
| 2 | W4 사유 창 | 확인 버튼 [기록 없음으로 처리] → **[기록 건너뛰기]**(1번과 같은 이름). 창 제목 “이 날은 돌봄이 없었나요?”와 사유 4개는 그대로 | Bỏ qua ghi chép |
| 3 | W2 시작 안내, 서버 오류 `no_care_day_exists` | “기록 없음으로 처리한 날이에요.” → “기록을 건너뛴 날이에요.”, “이 날은 ‘기록 없음’으로 정리된 날이에요.” → “이 날은 기록을 건너뛴 날이에요.” | Ngày này đã bỏ qua ghi chép. |
| 4 | W4 기간 거르기 | 날짜를 고르기 전 꺼진 버튼 “날짜를 골라 주세요” → [날짜 선택하기]. 고른 뒤 “○○ 기록 보기”는 그대로 | Chọn ngày |
| 5 | W4 탭 빈 상태 5개 | “… 기록이 없습니다.” → “… 기록이 없어요.” | 그대로 |
| 6 | A1 로그인 | “계정 준비가 끝나지 않았습니다. 관리자에게 문의하세요.” → “계정 준비가 끝나지 않았어요. 관리자에게 문의하세요.” | 그대로 |
| 7 | A2 회원가입 | “가입 코드가 맞지 않습니다. …” → “가입 코드가 맞지 않아요. …” | 그대로 |

관리자 M0 [기록 없음으로 정리], [처리 지우기], 결과 상태 '기록 없음 처리'와 표 `no_care_days`는 그대로입니다. 동작·API·표·상태 값은 바뀌지 않습니다. M3 인쇄 “PDF가 보이지 않으면 기록 PDF를 새 탭에서 열어 주세요.”도 그대로 둡니다.

## 검토한 대안

- 1번 [돌봄 없음 처리]: 상태 이름과 가까움 / 옆 [지금 쓰기]와 꼴이 다르고, 베트남어가 길어짐
- 1번 옆 버튼까지 [지금 작성하기]·[이어 작성하기]로 바꿈: ‘-하기’로 맞춤 / [이어 쓰기]는 용어집에 적힌 이름이라 결정이 하나 더 필요하고, 한국어가 두 줄로 넘어감
- 2번 창 확인 버튼만 그대로 둠: 바꿀 곳이 적음 / 카드와 창이 다른 이름이라 같은 일인지 헷갈림
- 말투 기준을 해요체나 합쇼체로 통일: 화면 전체가 고름 / 합쇼체 통일이면 약 330개가 바뀌고, 해요체 통일도 동의 문구·AI 원칙까지 건드려 얻는 것이 적음

## 사유

작성자가 버튼을 보고 할 일을 알 수 있게 동작 이름으로 부르고, 카드와 창은 같은 일이라 같은 이름을 씁니다. 나머지는 한 화면 안에서 해요체와 합쇼체가 섞인 문장만 해요체로 맞췄습니다.
