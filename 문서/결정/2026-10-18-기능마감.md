# 기능 추가 마감 10/23

- **상태:** 유효
- **정한 날·사람:** 2026-10-18 · 2dion
- **관련:** 기획안 결정 19, 시연·일정 v1.1

## 배경

외부 피드백에서 1주 안에 MVP를 만들고 그 뒤에 테스트하라는 조건이 나왔습니다(A8). 공모전 접수는 10/31, 파이널 제출은 11/8입니다.[1][2]

## 결정

- 기능 추가는 10/23까지 합니다. 10/24~30은 테스트·측정·제출물만 합니다.
- 기능은 빼지 않고 깊이만 줄입니다. 기능마다 '최소 구현 범위'를 둡니다(예: W6(도우미) = 교재 절 검색 + 답 + 출처, 인쇄·PDF = 브라우저 인쇄 CSS 1장).[3]

## 검토한 대안

- 10/31 직전까지 기능 개발: 기능은 더 깊어지지만 테스트 기간이 없음.
- 기능을 빼서 범위 줄이기: 일정은 편하지만 시연에서 보여 줄 흐름(교육용 기관, 인쇄 등)을 잃음(B2에서 반박).[2]

## 사유

1주 MVP 뒤 테스트 조건을 지키고, 시연 기능을 잃지 않기 위해서입니다.[3]

## 영향

- 10/24 이후 새 기능은 받지 않습니다. 꼭 필요하면 새 결정 파일로 남깁니다.
- 일정이 밀리면 담당자 화면은 R2(검토 화면) 1장으로 줄이되 수정·되돌리기·승인은 유지합니다.[3]
