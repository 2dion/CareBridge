# MVP 작성자 화면은 '한국어+베트남어' 병기 한 모드만

- **상태:** 유효
- **정한 날·사람:** 2026-10-25 · 2dion
- **관련:** 화면 설계 v1.1 '모든 화면 공통 규칙'(병기 원칙)·A2(회원가입)·W0(사용 안내)·W5(내 정보), 기획안 v1.1 '범위'('한국어만 보기'는 여유 시), 10/22 멘토링 회의록 결정 8, [받아쓰기(STT)는 Groq Whisper 무료 API로](2026-10-20-stt-groq.md) 덧붙임

## 배경

10/22 멘토링에서 작성자가 W5(내 정보)에서 '한국어' / '한국어+베트남어'를 골라 "보조 바퀴를 떼는 단계"로 설명하기로 했습니다.[1] 화면 설계도 W0(사용 안내)·A2(회원가입)·W5에 언어 선택을 두었습니다.[2] 두 모드를 모두 만들면 화면마다 병기 줄을 켜고 끄는 분기와 시험이 두 배가 되는데, 공모전 접수(10/31)와 파이널 제출(11/08)까지 시간이 짧습니다.[3]

## 결정

1. MVP는 작성자 화면을 **'한국어+베트남어' 병기 모드 하나**로만 만듭니다. 무엇을 병기할지는 화면 설계 v1.1 병기 원칙(내 말은 그대로, 남이 쓴 내용은 병기, 화면 틀은 한국어)을 따릅니다.[2]
2. '한국어만' 모드는 **여유 시**로 미룹니다. 기획안 v1.1 범위표의 "'한국어만 보기' 여유 시"와 같습니다.[4]
3. 그래서 MVP 화면에서 언어를 고르는 칸을 빼거나 숨깁니다: W0 언어 선택, W5 '언어', A2 ⑥ 모국어.
4. 표·API(공통 계약)는 그대로 둡니다. `profiles.native_lang`과 `/api/auth/signup`의 `native_lang`은 남기고, 작성자·교육생 코드로 가입하면 화면이 `vi`를 보냅니다(담당자 코드면 지금처럼 서버가 `ko`로 저장). 나중에 '한국어만' 모드를 켤 때 같은 칸을 씁니다.

## 검토한 대안

- **두 모드 모두 MVP(10/22 멘토링안):** '보조 바퀴' 이야기를 화면으로 보여 줄 수 있지만, 모든 작성자 화면에 분기가 생기고 시험이 두 배입니다.
- **'한국어만' 한 모드:** 가장 가볍지만 케어브릿지의 차별점(한국어-모국어 병기, 10/15 멘토링)이 시연에서 사라집니다.[5]

## 사유

병기 모드가 서비스의 차별점을 보여 주는 모드이고, 병기 원칙으로 화면 틀은 이미 한국어라 '한국어 중심, 모국어 보조' 방향도 지킵니다. 칸(native_lang)을 남겨 두어, 일정 뒤 '한국어만'을 켤 때 표·API를 다시 바꿀 필요가 없습니다.

## 영향

- **화면 설계 v1.1:** 공통 규칙 병기 원칙에 'MVP는 병기 모드 하나' 한 줄. W0·W5·A2의 언어 선택을 '여유 시'로.
- **화면(프론트엔드 담당):** 피그마 M01(사용 안내 1/3)의 '한국어만 / 한국어+베트남어' 버튼과 M19(내 정보)의 '언어 선택' 메뉴를 빼거나 숨김. A2에서 모국어 칸을 숨기고 `native_lang: "vi"`를 보냄.
- **서버(백엔드 담당):** 바뀔 것 없음. 받아쓰기 언어는 STT 결정 덧붙임대로 작성자(`vi`)는 자동 감지.
- **발표:** '보조 바퀴'(한국어만 모드로 넘어가기)는 다음 단계 계획으로 설명합니다.
