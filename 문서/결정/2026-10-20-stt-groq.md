# 받아쓰기(STT)는 Groq Whisper 무료 API로

- **상태:** 유효
- **정한 날·사람:** 2026-10-20 · 2dion
- **관련:** 기술 선택 v1.1 §5, [텍스트 AI는 코디세이 공개 API로](2026-10-20-코디세이api.md), [코디세이 API 사용 방법 v1.0](../설계/코디세이api-v1.0.md) §6

## 배경

v1.1은 받아쓰기를 서버에서 OpenAI 음성 인식으로 한다고 정했지만 결제 담당이 없었습니다.[1] 코디세이 공개 API에는 STT가 없고, 채팅 모델에 음성을 넣는 방법도 10/20 시험에서 400 `unsupported_feature`로 막혔습니다.[2]

## 결정

- 받아쓰기는 서버에서 Groq의 OpenAI 호환 음성 인식 API `POST https://api.groq.com/openai/v1/audio/transcriptions`로 합니다.
- 모델은 `whisper-large-v3`(오류율이 더 낮고 다국어에 권장), 언어는 `language=ko`로 지정합니다.[3]
- 무료(Free) 요금제로 시작합니다. 결제 카드는 등록하지 않습니다.
- 키는 서버 환경 변수(Vercel)와 클라우드 환경 네트워크 시크릿에만 둡니다. 코드는 OpenAI 호환 호출 한 곳으로 만들어, 주소·키·모델만 바꾸면 OpenAI 음성 인식으로 옮길 수 있게 합니다.
- Groq 콘솔의 Data Controls에서 Zero Data Retention을 켭니다.[4]

## 검토한 대안

- OpenAI 음성 인식(v1.1): 품질 검증, 코드 그대로 / 결제 카드 필요.
- 브라우저 내장 인식: 무료, 키 없음 / 파이어폭스 미지원, 아이폰 사파리 끊김.
- Google STT, 네이버 CLOVA, Deepgram: 한국어 품질 좋음 / 카드 등록·설정이 무겁거나 무료 크레딧이 끝나면 유료.
- Google Gemini 3.5 Transcribe(무료 등급): 한국어·베트남어 섞인 말 자동 인식 / 무료 등급 데이터는 Google 제품 개선에 쓰이고 속도 제한이 있음, 비교 시험에서 숫자·양을 그럴듯하게 바꿈(아래 '비교 시험').[7][8]
- 브라우저에서 Whisper 직접 실행: 무료, 음성이 기기 밖으로 안 나감 / 폰에서 느리고 처음 다운로드가 큼.
- 코디세이에 STT 추가 요청: 키 하나로 끝남 / 시기 모름. 함께 요청은 해 둠.

## 비교 시험 (10/20)

**왜:** 결정 뒤 Gemini 3.5 Transcribe가 무료라는 소개가 있어, 같은 녹음으로 Groq와 비교했습니다.[8]

- 방법: 코디세이 TTS로 만든 합성 음성 2개(한국어 1문단, 한국어·베트남어 섞인 3문장)를 팀장 맥 터미널에서 두 API에 넣고 정답과 비교. 3번 반복.
- 한국어: 두 엔진 모두 '죽 반 그릇'의 '반'만 틀림. Groq는 '죽판 그릇'(없는 말이라 사람이 바로 알아챔), Gemini는 '죽 한 그릇'(양이 바뀌어 검토 때 놓치기 쉬움). 숫자는 둘 다 아라비아 숫자로 바꿈. 걸린 시간 Groq 1~4초, Gemini 6~30초.
- 섞인 말: 한국어 두 문장은 둘 다 정확. 베트남어 'Bà ăn hết rồi'는 둘 다 같은 '다 안 했죠'로 씀. 합성 음성이 베트남어를 한국어 발음으로 읽은 탓으로 보여, 이 시험으로는 우열을 가리지 않음.
- 판단: Groq 유지. 빠르고, 틀린 곳이 티가 나서 W3(작성자 확인)·R2(담당자 검토)에서 잡기 쉬움.
- 남은 것: ⚠️ 사람 목소리(외국인 발음, 베트남어 섞인 말) 샘플로 다시 잽니다. 받아쓰기 결과를 그대로 믿지 않고 사람이 확인하는 단계가 꼭 필요하다는 근거로도 씁니다.

## 사유

비용 없이 v1.1과 같은 '서버 STT' 구조를 지키고, 한도나 품질이 부족하면 주소만 바꿔 OpenAI로 옮길 수 있기 때문입니다.

## 영향

- 서버: 받아쓰기 함수가 Groq를 부릅니다. 업로드 파일은 무료 25MB 안이어야 합니다. 5분 녹음(webm·mp4)은 보통 이보다 훨씬 작습니다.[3]
- 한도: 무료 요금제는 분당·하루 요청 수와 시간당·하루 음성 초 수에 상한이 있습니다. ⚠️ 정확한 값은 Groq 콘솔 `/settings/limits`에서 확인해 이 파일에 적습니다(Developer 요금제 기본값: 분당 20건, 하루 2,000건, 시간당 7,200초, 하루 28,800초).[5] 넘으면 429가 오니 [다시 시도]·[글로 쓰기]로 처리합니다.
- 비용 계산: 10초보다 짧은 요청도 10초로 셉니다.[3]
- 데이터: 기본적으로 추론 데이터를 보관하지 않지만, 장애·남용 조사를 위해 최대 30일 기록될 수 있습니다. Zero Data Retention을 켜고, 합성 사례만 씁니다(AGENTS.md 원칙 9).[4]
- 테스트: 크롬 webm, 사파리 mp4, 외국인 발음 샘플 5개로 받아쓰기 품질을 잽니다(기술 선택 '확인').
- 문서: 기술 선택 v1.1 §5·요약, 코디세이 API 사용 방법 §6을 고칩니다.
