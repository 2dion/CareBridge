# 도우미(W6)는 같은 기관의 같은 질문에 저장된 답을 다시 쓰고, 교재는 관련 문단만 보낸다

- **상태:** 유효
- **정한 날·사람:** 2026-11-03 · 백엔드 담당 (팀장이 이슈 #229로 범위를 정함)
- **관련:** AI 규칙 v2.0.2 W6 9번(새 줄), 결정 [도우미대화저장](2026-10-31-도우미대화저장.md)(저장한 답을 읽는 용도가 하나 늘어남), 데이터 구조 v2.3.1 `helper_messages`(표·칸 그대로, 서버 전용 함수 `find_helper_answer` 추가), 코디세이 API 사용 방법 v2.0.0 §4, 이슈 #229

## 배경

- 10/31 코디세이 콘솔 확인: 도우미 질문 1건 = Haiku 입력 약 7,900 + 출력 500~650 → 차감 약 4,250토큰. 거의 전부가 교재 상위 3절(5,000~7,000자)을 통째로 보내는 입력입니다.[1]
- 같은 작성자 계정이 같은 질문을 5번 보내 5번 다 Claude를 불렀고, 답도 '못 찾음 → 찾음'으로 흔들렸습니다.[1]
- 월 한도 1,000,000으로 도우미만 쓰면 약 230건이라, 기록 1건(약 20,000)과 함께 쓰면 시연·테스트 기간에 빠듯합니다.[2]

## 결정

1. **같은 질문 재사용:** 같은 기관에서 같은 질문이 이미 `helper_messages`에 **교재에서 찾은 답(`found = true`)** 으로 있으면 Claude를 부르지 않고 그 답(ko·native·source·found)을 돌려주고, 이번 질문도 새 행으로 저장합니다. '같은 질문'은 검색용 한국어(`question_ko`가 있으면 그것, 없으면 `question`)를 소문자로 바꾸고 빈칸·문장부호를 뺀 뒤 비교합니다. 작성자 모국어가 같은 행만 씁니다(번역 줄이 다른 언어이면 안 되므로). 가장 최근 행을 씁니다.
2. **못 찾은 답은 재사용하지 않음:** '교재에서 찾지 못했어요'는 교재가 늘거나 검색이 나아지면 달라질 수 있어, 다시 검색합니다.
3. **안전 안내는 그대로:** 재사용한 답에도 서버가 건강·안전 낱말을 검사해 안내를 붙입니다(저장된 답에 이미 있으면 두 번 붙이지 않음). 교육용 기관의 '강사' 문구도 지금처럼 서버가 정합니다.
4. **교재 문단만 보내기:** 절 전체 대신 질문 낱말(핵심 낱말 포함)이 든 문단과 그 앞뒤 문단만, 절당 1,500자까지 보냅니다. 맞는 문단이 없으면 절 앞부분 1,500자입니다. 출처(장·절·쪽)는 그대로입니다.
5. **점수 낮은 절 빼기:** 교재 순위에서 1위 점수의 1/3 미만인 절은 보내지 않습니다.
6. **답 길이:** 시스템 프롬프트에 '3문장 이내'를 더합니다.
7. **바뀌지 않는 것:** 화면·API 입출력, '교재에 있는 내용만 답한다'(W6 1·2번), 저장 규칙(W6 8번), 질문 하나에 호출 한 번.

## 검토한 대안

- **대안 A: 교재 전체 프롬프트 캐싱:** 반복 질문에 강함 / 캐시 쓰기(1.25배, 약 15,000)가 5분 안에 다음 질문이 없으면 매번 나가, 띄엄띄엄 쓰는 도우미에는 손해. 버림
- **대안 B: 못 찾은 답도 재사용:** 호출이 더 줆 / 교재가 늘어도 계속 '못 찾음'. 버림
- **대안 C: 재사용 판정을 AI(의미 비교)로:** 비슷한 질문도 잡음 / 그 판정에 호출이 들고 짐작이 섞임. 버림(글자 비교만)
- **대안 D: 재사용 때 저장하지 않음:** 행이 덜 쌓임 / 대화 묶음·'이전 대화'에 그 질문이 빠지고, 관리자가 교육생의 질문 빈도를 못 봄. 버림
- **채택:** 글자 비교 재사용 + 문단 추리기 + 낮은 절 제외 + 답 길이

## 사유

- 반복 질문은 0토큰, 새 질문은 입력이 절반 아래로 줄어 월 한도 안에서 시연·테스트를 돌릴 수 있습니다.
- 답의 근거(교재 절·문단)와 출처 규칙은 그대로라 '교재에 있는 내용만' 원칙을 다시 검증할 필요가 없습니다.
