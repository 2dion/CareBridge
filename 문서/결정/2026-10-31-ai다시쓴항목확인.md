# AI가 다시 쓴 항목도 작성자가 다시 확인한다

- **상태:** 유효
- **정한 날·사람:** 2026-11-03 · JiNS03 (A안 선택, 10/31 제안)
- **관련:** 이슈 #236, AGENTS.md 바꾸지 않는 원칙 1, 데이터 구조 v2.0.1 submit 조건, 화면 설계 v2.0.1 W3, 결정 [2026-10-28-항목하나저장](2026-10-28-항목하나저장.md)

## 배경

[내용 수정]의 글·음성으로 AI가 항목을 다시 쓰면 `source = worker`, `confirmed_by_worker = false`로 저장됩니다. 결정 기록은 다시 확인을 요구했지만, 전송 조건이 `source = worker`를 확인된 것으로 봐서 AI가 쓴 문장을 확인 없이 전송할 수 있었습니다.

## 결정

1. 전송 조건은 9개 항목 모두 `confirmed_by_worker`입니다. `source = worker`만으로는 전송할 수 없습니다.
2. 작성자가 직접 고치면 W3가 `confirmed_by_worker = true`를 함께 보내므로 다시 묻지 않습니다.
3. AI가 다시 쓴 항목은 다시 [확인 완료]를 받을 때까지 'AI 초안'으로 표시합니다.
4. 같은 조건을 화면, API, DB에 둡니다.

## 검토한 대안

- 지금 동작 유지: 코드 변경 없음 / 원칙 1과 어긋남
- `item` 모드의 출처를 `ai`로 저장: 뜻은 맞음 / 작성자 요청으로 쓴 값을 Agent가 덮어쓸 수 있어 원칙 4와 어긋남

## 사유

작성자가 입력한 글이어도 공식 기록에 남는 문장은 AI가 썼으므로, 원칙 1에 따라 작성자가 확인해야 합니다.
