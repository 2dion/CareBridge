# 교육용 기관의 강사 검토는 담당자와 같은 흐름으로

- **상태:** 유효
- **정한 날·사람:** 2026-10-25 · 2dion
- **관련:** 기획안 결정 12(교육용 기관), 데이터 구조 v1.4 '기록 상태 변화'·records.status·권한 규칙·공통 계약 API 경로, 화면 설계 v1.1 '교육용 기관에서 달라지는 점'·R2(검토 화면)·R3(승인한 기록), 시연 시나리오 3

## 배경

v1.1에서 교육용 기관의 강사는 수정·승인 없이 [코멘트 보내기]만 했고, 기록은 commented(코멘트 받음)로 끝났습니다.[1][2] 담당자의 [되돌리기](사유 필수, 작성자가 고쳐 다시 보냄)와 갈래가 달라서 화면·서버·테스트를 두 벌 만들어야 하고, 교육생은 현장에서 쓸 되돌림 흐름을 연습하지 못합니다. W1(오늘) 정리 중 FE용 설명에서 둘의 차이가 드러났습니다.[3]

## 결정

1. 교육용 기관의 강사는 R2(검토 화면)에서 담당자와 **똑같이** 합니다: 항목 수정, [확인함]/[기록 안 함], [되돌리기](사유 필수), [승인]. 승인 조건(정하지 않은 '확인 필요' 0개)도 같습니다.
2. `records.status`에서 `commented`를 뺍니다. draft / submitted / returned / approved 4개입니다. `record_events.type`에서도 뺍니다.
3. `comments` 표와 `POST /api/records/:id/comment`를 뺍니다. 표 13개 → 12개, API 11개 → 10개. 강사의 가르침은 되돌린 사유와 항목 수정 이력(record_events)으로 남습니다.
4. 연습 기록은 상태가 아니라 기관의 `is_training`으로 가립니다. 화면 상단 '연습용' 띠는 그대로, 인쇄·PDF에는 '연습용'을 찍고, 승인 통계에서는 교육용 기관을 뺍니다.

## 검토한 대안

- **강사에게 [되돌리기]만 더하기 (승인은 없음):** 실제 승인 기록이 생기지 않는 점은 좋지만, 코멘트·되돌리기·승인 없음이 섞여 갈래가 오히려 늘고 교육생이 승인까지 가는 흐름을 볼 수 없습니다.
- **그대로 (코멘트 → commented):** 문서를 안 고쳐도 되지만, 두 갈래를 만들고 테스트해야 하고 교육생이 되돌림 흐름을 연습하지 못합니다.

## 사유

화면·서버·테스트를 한 벌로 줄이고, 교육생이 현장과 같은 흐름을 연습하게 하기 위해서입니다. 연습 기록이 실제 승인 기록과 섞이는 문제는 기관 분리(RLS)와 `is_training` 표시로 막습니다.

## 영향

- **데이터 구조:** v1.3 → v1.4 (status 값, comments 표, API, 권한 규칙). v1.3은 `문서/보관/설계/`로.
- **기획안 v1.1:** 결정 12, 시연 ③ 설명, 최소 범위 표.
- **화면 설계 v1.1:** '교육용 기관에서 달라지는 점'. R2·R3는 담당자와 같고 '연습용' 표시만 더함. 화면문구 v1.0의 '코멘트 받음' 배지 뺌.
- **작성자 이력 화면 (여유 시):** 코멘트를 빼면 교육생이 배우는 자리는 되돌림·수정 이력입니다. W4(기록함) 승인됨 상세에 읽기 전용 '되돌림·수정 이력'을 여유 시 항목으로 더합니다. record_events에 이미 남는 데이터(되돌림 사유, 고치기 전·후, [기록 안 함] 사유)를 보여 주기만 하고 새 표는 없습니다. 사유 번역은 마지막 것만 남습니다(2dion 10/25).
- **AI 규칙 v1.1:** 짧은 번역 대상에서 '강사 코멘트' 뺌.
- **DB(백엔드 담당):** 마이그레이션에서 status·event type 검사의 `commented`, comments 표, 강사 막는 트리거(`general_org_only`, `training_reviewer_read_only`, `training_org_only`) 정리. 교육용 기관에서도 승인 허용. 오류 키 `record_locked`는 approved만.
- **화면(프론트엔드 담당):** R2의 강사 갈래와 [코멘트 보내기] 빼기, W1·W4의 '코멘트 받음' 배지 빼기, `web/lib/demo/state.ts`의 commented 정리. 인쇄에 '연습용'.
- **테스트(QA 담당):** 강사 되돌리기·승인, 교육용 기관 승인이 통계에 안 들어감, 교육용 PDF '연습용', 다른 기관 기록 안 보임.
- **시연:** 시나리오 3을 '강사 되돌리기 → 교육생이 고쳐 다시 보냄 → 강사 승인 → 연습용 PDF'로.
