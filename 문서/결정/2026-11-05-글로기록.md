# 글 입력 기록 방법의 이름을 [글로 기록]으로 맞춘다

- **상태:** 유효
- **정한 날·사람:** 2026-11-05 · 기획 담당 제안, 프론트엔드 담당 반영 (이슈 #327)
- **관련:** 이슈 #327, 결정 [용어통일](2026-10-29-용어통일.md), 용어집 v2.0.4, 화면 설계 W2·W3·W4

## 배경

기록 시작 화면에서 같은 기록 방법을 [음성으로 기록]과 [글로 쓰기]로 다르게 불렀다. 이슈 #327에서 두 이름의 꼴을 맞추도록 한국어·베트남어 문구를 정했다.

## 결정

1. [음성으로 기록]은 유지하고 글 입력 방법은 [글로 기록]으로 부른다. 베트남어는 `Ghi bằng chữ`로 맞춘다.
2. W2 기록 시작·녹음 대체 입력·글 입력 화면 제목, W3 처리 실패의 대체 입력 버튼에 같은 이름을 쓴다. 화면 설계의 W2·W3·W4 설명과 코드 주석도 맞춘다.
3. 용어집의 쓰는 이름을 바꾸고 [글로 쓰기]와 `Viết trực tiếp`는 쓰지 않는 이름으로 옮긴다. 용어집 버전은 v2.0.4로 올리고 v2.0.3 원본은 보관한다.
4. 경로 `write`, 입력 방법 값 `text`, API·표·권한·상태 값·기록 생성 동작은 유지한다.

## 검토한 대안

- [글로 쓰기] 유지: 익숙한 표현이지만 같은 기록 방법의 이름이 [음성으로 기록]과 맞지 않는다.
- [음성으로 기록]도 바꾸기: 이미 안내와 화면에서 쓰는 이름을 함께 바꿔야 하므로 이번 범위에서 고르지 않는다.
- **채택:** 한국어 [글로 기록], 베트남어 `Ghi bằng chữ`.

## 사유

같은 기록 방법의 한국어·베트남어 이름을 같은 꼴로 맞추고, 시작 화면과 실패 복구 화면에서 같은 동작임을 알아보기 쉽게 한다.

## 영향

- **문서:** 용어집 v2.0.4, 화면 설계의 기록 방법 이름, 기준 문서 링크.
