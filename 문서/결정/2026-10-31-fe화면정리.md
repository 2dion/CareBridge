# FE 마감 화면의 선택과 반영

- **상태:** 유효 (FE 담당 작업 요청과 각 이슈의 추천안 기준)
- **정한 날·사람:** 2026-10-31 · 프론트엔드 담당
- **관련:** #148, #101, #102. #101·#102의 10/29 팀장 댓글은 담당 라벨이 붙은 사람이 정해 진행하도록 위임했습니다.

## 결정

1. **#148:** M0 기록 현황, 경로 `/overview`. 관리자·강사의 첫 화면과 메뉴 첫 항목으로 사용합니다. M1은 받은 시각이 오래된 순이며, 셋째 칩 이름은 ‘확인 필요 0’입니다. 사용자 작업 목록에 따라 이슈의 추천안을 적용하며 별도의 팀장 확정이 있었다고 표기하지 않습니다. M1 기본 날짜는 전체로 두어 필터 전체에서 M0·메뉴와 같은 수를 보입니다.
2. **#101:** 추천 ⑥·⑦·⑧을 함께 적용합니다. 승인본 화면은 내용 있는 다음 확인사항을 맨 위, 확인 필요 상태 항목(관리자 처리 배지 유지)를 그다음에 표시합니다. 비어 있는 언급 없음은 기본 접힘으로 모읍니다. 관리자 처리 배지와 빈 항목의 펼치기를 유지하며 인쇄/PDF와 전송본 순서는 바꾸지 않습니다.
3. **#102:** A안. 앱이 제공하는 녹음 준비 제목·안내 두 줄은 한국어 아래 베트남어를 붙입니다. 사용자가 녹음한 말이나 직접 쓴 원문을 자동 병기하는 변경은 아닙니다. 한 녹음은 한 언어로 받는 10/30 결정도 유지합니다.

## 사유와 대안

- 현황 숫자와 검토 표를 분리해 M1 목록이 아래로 밀리지 않게 합니다. 복잡한 그래프·새 통계를 추가하지 않습니다.
- 승인 기록의 다음 방문 할 일을 빨리 보고, 빈 항목은 필요할 때 펼치게 합니다. 법정 인쇄 순서를 화면 때문에 바꾸지 않습니다.
- 앱 안내는 작성자 원문과 달리 읽고 행동해야 하는 내용이므로 병기합니다. 한국어만 유지하는 대안은 선택하지 않았습니다.

## 영향

화면 설계의 문장·메뉴·흐름 그림과 용어집의 M0/PC 메뉴를 맞춥니다. DB·RLS·API·상태 값·승인 조건을 바꾸지 않습니다. 실제 DB 작업이나 자동 배포 설정 변경은 없습니다. GitHub 쓰기 권한 오류로 이슈 댓글은 아직 남기지 못했으며 업로드 시 이 결정 내용을 #101·#102에 전달해야 합니다.
