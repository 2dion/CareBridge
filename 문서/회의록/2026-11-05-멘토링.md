## 2. 최종 발표 준비 피드백

### 2-1. PPT 디자인 및 구성 원칙

- **AI 생성 자료처럼 보이지 않도록:** Claude에서 생성한 듯한 정형화된 디자인과 구성은 지양하고, 팀의 기획 의도와 프로젝트 특성이 드러나도록 제작.
- **구조적인 발표 흐름:** 평가위원이 발표 도중 길을 잃지 않도록 목차와 각 페이지의 내용을 논리적으로 연결.
- **페이지 번호:** 발표 자료에 페이지 번호를 삽입하여 현재 발표 위치를 쉽게 파악할 수 있도록 구성.
- **기술적 상세 내용은 부록으로:** 기술 스택, 참고 출처 등 상세 자료는 본문에서 간결하게 다루고 부록에 정리. 질의응답 시 근거 자료로 활용.

### 2-2. PPT 페이지별 구성

| 구분 | 주요 내용 | 비고 |
| --- | --- | --- |
| 1페이지 | 케어브릿지 로고 | 표지 |
| 2페이지 | 발표 목차 | 필수, 구조적으로 구성 |
| 3페이지 | 팀원 소개 및 프로젝트 일정 | 역할과 진행 일정 |
| 본문 | 문제 정의 | 데이터 기반으로 문제 도출 |
| 본문 | 주요 기능 | 작성자·관리자 기능 구분 |
| 본문 | AI 활용 과정 | 프로젝트에서 AI를 어떻게 활용했는지 설명 |
| 본문 | 기대효과 | 서비스 도입 효과 및 기대 성과 |
| 부록 | 기술 스택, 참고 출처 등 상세 자료 | 질의응답 대비 |

※ 1~3페이지의 구성은 멘토 피드백을 반영했으며, 이후 본문 항목의 순서 및 페이지 수는 발표 흐름에 맞춰 조정합니다.

### 2-3. 발표 내용 구성 시 유의사항

**① 데이터 기반 스토리라인 구성**

- 단순히 서비스 기능을 나열하는 것이 아니라, 객관적인 데이터를 바탕으로 문제를 정의하고 해결 과정까지 단계적으로 설명.
- 문제 정의 → 해결 방향 → 주요 기능 → AI 활용 → 기대효과가 자연스럽게 이어지도록 구성.

**② 작성자·관리자 기능 구분**

- 주요 기능 설명 시 작성자와 관리자의 역할을 구분하여 소개.
- 각 사용자에게 어떤 문제를 해결해 주는지 명확히 전달.

**③ AI 활용 과정 설명**

- 프로젝트에서 AI를 어떻게 활용했는지 구체적으로 설명.
- AI 활용 자체를 강조하기보다 실제 문제 해결에 어떻게 기여했는지 중심으로 정리.

**④ 평가위원 관점의 자료 구성**

- 목차와 페이지 번호를 통해 전체 발표 흐름을 쉽게 파악할 수 있도록 구성.
- 슬라이드마다 핵심 메시지를 명확히 전달.
- 상세 기술 정보는 부록에 배치하여 본문의 가독성을 확보하고 질의응답에 대비.
