## 유의사항 (원문 7개 요약)

1. 이동서비스를 제공하면 √표와 차량번호
2. 목욕은 소요시간(분)과 제공방법에 √표
3. 식사는 종류와 섭취량에 √표
4. 화장실이용하기는 급여제공시간 동안 소변·대변 총 횟수 (기저귀 사용 시 교환 횟수)
5. 신체·인지기능 향상 프로그램은 제공한 프로그램명
6. 특이사항은 상태변화 시 조치사항 등 (여백 부족 시 별지 가능)
7. **각 항목별 서비스를 제공한 종사자가 작성자 란에 서명**

## 제16호와 다른 점

| 칸 | 제15호 (주·야간보호) | 제16호 (시설급여) |
|---|---|---|
| 머리말 | 침실·수급자 상태 칸 없음 | 침실 호(실), 수급자 상태 √ |
| 일정 | **총시간·시작/종료시간·이동서비스(차량번호)** | 날짜만, 맺음에 입·퇴소·외박·외출 시간 |
| 목욕 | **소요시간(분) + 방법(전신입욕/샤워식)** | 체크 + 전·후 상태 |
| 식사 종류 | 일반식 / 죽 / **유동식(미음)** | 일반식 / 죽 / 유동식(튜브영양공급식) |
| 체위변경 | **칸 없음** | 2시간마다 √ |
| 산책·외출 | **칸 없음** | □ 산책 / □ 외출 |
| 기능회복훈련 | **인지활동형프로그램** 칸 있음 | 없음 |
