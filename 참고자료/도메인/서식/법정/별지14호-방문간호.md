# 별지 제14호서식 장기요양급여 제공기록지(방문간호)

| 항목 | 내용 |
|---|---|
| 근거 법령 | 노인장기요양보험법 시행규칙 제18조 |
| 서식 개정일 | **2025. 12. 12.** |
| 확인일 | 2026-10-17 (국가법령정보센터) |
| 원문 파일 | [원문/별지14호-방문간호-2025.12.12.pdf](원문/별지14호-방문간호-2025.12.12.pdf) |
| 기록 단위 | 1장 = 방문 3회 |
| 케어브릿지 쓰임 | **제외** (간호(조무)사가 쓰는 방문간호 기록) |

## 칸 구성 (요약)

| 영역 | 칸 |
|---|---|
| 머리말 | 장기요양기관기호·기관명, 장기요양등급, 수급자 성명, 생년월일, 장기요양인정번호 |
| 방문간호지시서 | 의료기관 명칭, 발급일, 유효기간, 의사면허번호, 방문횟수(주 ○회) |
| 방문마다 | 년월일, 시작·종료·총시간 |
| 기본 | 혈압, 맥박, 체온 |
| 내용 | 건강관리(분): 관절오그라듦 예방, **투약관리**, 기초건강관리, 인지훈련 / 간호관리(분): 욕창·영양·통증·배설·당뇨발관리, 호흡기·투석·구강간호 |
| 특이사항 | 수급자 상태, 처치 내용, 가족 상담·교육 내용 |
| 확인 | 장기요양요원 성명(서명), 수급자 또는 보호자 성명(서명) |

## 케어브릿지에 주는 의미

- 투약관리·혈압·맥박·체온이 **의사 지시서를 받는 방문간호 기록**의 핵심 칸입니다. 제16호의 "건강 및 간호관리" 영역과 세부 항목이 같습니다.
- 케어브릿지 MVP는 이 서식을 다루지 않습니다. 요양보호사 기록에서 복약은 **"드신 것을 봤는지"** 수준의 관찰만 남기고, 투약관리 자체는 이 영역(간호인력)으로 둡니다.
