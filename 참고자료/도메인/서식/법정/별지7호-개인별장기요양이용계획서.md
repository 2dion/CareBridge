## 칸 구성

| 영역 | 칸 |
|---|---|
| 머리말 | 장기요양인정번호 - 이용계획서번호 |
| 수급자 | 성명, 생년월일, 장기요양등급, 인정유효기간 |
| 이용 한도 | 재가급여 월 한도액, 시설급여 1일당 금액(노인요양시설 일반·치매전담실 가형/나형, 노인요양공동생활가정 일반·치매전담형), 본인부담율(재가·시설 %) |
| 장기요양 필요내용 | **장기요양 필요영역 / 장기요양 욕구 / 장기요양 목표 / 장기요양 필요내용** |
| 수급자 희망급여 | 서술 |
| 유의사항 | 서술 |
| 장기요양 이용계획 및 비용 | 급여종류, 횟수(주·월 ○회), 장기요양급여비용, 본인부담금, 합계 / 복지용구 |
| 발급 | 지사 연락처·담당자, 발급일, 국민건강보험공단 이사장 직인 |

## 케어브릿지에 주는 의미

- **장기요양 필요영역·필요내용**이 공단이 정한 "이 어르신에게 필요한 돌봄"의 출발점입니다. 기관의 급여제공계획서(제11호의3·4)는 이 항목을 이어받아 세부 제공내용을 정합니다.
- 비용·본인부담금 칸은 케어브릿지 기록과 관계없습니다. 어르신 정보에는 **등급, 인정유효기간, 급여 유형(시설/재가)**만 있으면 됩니다.
- 실제 계획서는 개인정보라 데모·개발에는 합성 사례만 씁니다.
