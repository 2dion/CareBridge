# 코디세이 공개 API 매뉴얼 (받은 자료 옮김)

2026-10-20 옮김 · @2dion

## 이 파일은 왜 있나

- **목적:** 코디세이가 학습자에게 준 공개 AI API 안내를 저장소 안에서 바로 찾게 합니다. 팀이 쓰는 방법은 [코디세이 API 사용 방법](../../문서/설계/코디세이api-v1.0.md)에 따로 정리합니다.
- **배경:** 원본은 노션 페이지와 로그인해야 열리는 API 콘솔에 있어, 팀원마다 찾아 들어가야 하고 내용이 바뀌어도 알기 어렵습니다.[1][2]
- **근거:** 코디세이 공개 API 학습자 매뉴얼(노션), API 콘솔의 '문서' 탭입니다. 둘 다 2026-10-20에 팀장이 받아 옮겼습니다.[1][2]
- **사유:** 받은 자료는 `참고자료/`에 둔다는 저장소 규칙을 따릅니다. 원문을 고치지 않고 옮기되, 화면 캡처 이미지와 개인 프로필 정보는 뺐습니다.

⚠️ 원본은 계속 바뀔 수 있습니다. 매뉴얼은 "QA 환경" 기준이고 키 만료·요청 속도 제한 같은 정책은 "협의 중"입니다.[1] 다르면 원본을 따르고 이 파일을 고칩니다.

## 1. 공개 API란 (매뉴얼 1장)

학습자가 외부 LLM 회사의 키를 직접 받지 않아도, 코디세이가 발급하는 API 키 하나로 AI 기능을 쓰게 하는 기능입니다. 호출 비용은 소속 기관의 LLM 키로 정산됩니다.[1]

| 분류 | 제공 기능 | 엔드포인트 |
| --- | --- | --- |
| 텍스트 (Anthropic 규격) | Claude 모델 채팅 | `/v1/messages` |
| 텍스트 (OpenAI 규격) | GPT 모델 채팅 | `/v1/chat/completions` |
| 모델 목록 | 사용 가능 모델 조회 | `/v1/models` |
| 이미지 생성 | 이미지 생성 (b64 수신) | `/api/v1/images` |
| 음성 생성(TTS) | 텍스트 → 음성 (b64 수신) | `/api/v1/audio/tts` |
| 영상 생성 | 생성 요청 → 상태 확인 → 다운로드 | `/api/v1/videos`, `/api/v1/videos/{id}`, `/api/v1/videos/{id}/download` |

> 음성 인식(STT, 음성 → 글자)은 목록에 없습니다.

매뉴얼 첫머리 안내: 키를 Claude·Cursor 같은 채팅·코드 에이전트에 상시 연결하면 호출마다 맥락을 통째로 보내 토큰을 크게 쓰고 월 한도가 금방 소진되니, 프로젝트를 만들 때 호출하는 용도를 권장합니다.[1]

## 2. 주소 (콘솔 문서 탭)

| 항목 | 값 |
| --- | --- |
| Public API Base URL | `https://copa.codyssey.kr` |
| OpenAI 호환 Base URL (Cursor 등) | `https://copa.codyssey.kr/v1` |
| 콘솔 | `https://usr.codyssey.kr/daejeon/public-api-console` (로그인 필요) |

매뉴얼: Base URL은 환경(QA/운영)에 따라 다르니 콘솔 문서 탭에 표시된 값을 씁니다.[1]

## 3. 키 (매뉴얼 3~4장)

- 콘솔 'API 키' 탭 → [+ 키 발급] → 라벨 입력, 호환 방식(Anthropic 또는 OpenAI) 선택 → 키 원문 표시.
- **키 원문은 발급 직후 한 번만 보입니다.** 잃어버리면 폐기하고 새로 발급합니다.
- 호환 방식별로 1개씩(Anthropic 1개 + OpenAI 1개)까지 발급합니다.
- 서버에는 키의 해시와 앞·뒤 일부만 저장됩니다.
- 키 재표시, 만료 정책, 요청 속도 제한(rate limit)은 협의 중입니다.
- 소속 기관에 그 회사(Anthropic/OpenAI)의 키가 없으면 발급이 막히고 사유가 보입니다.
- 콘솔 화면에는 키마다 허용 IP/CIDR, 모델 정책(전체 허용 / 목록만 허용 / 목록만 차단), 범위(채팅·이미지·오디오·비디오) 칸이 있습니다.[2]
- 수정(연필): 라벨과 호환 방식만 바꿈. 폐기(휴지통): 즉시 무효, 되돌릴 수 없음.

## 5. 호출 방법 (매뉴얼 7장, 콘솔 코드 예제)

### 인증

`Authorization: Bearer <키>` 또는 `x-api-key: <키>` 헤더로 보냅니다. 두 방식 모두 모든 엔드포인트에서 동작합니다.[1]

### 텍스트: 두 규격의 차이

| | OpenAI 호환 | Anthropic |
| --- | --- | --- |
| 경로 | `/v1/chat/completions` | `/v1/messages` |
| max_tokens | 선택 | 필수 |
| 시스템 프롬프트 | messages의 `role: "system"` | 최상위 `system` 필드 |
| 응답 본문 | `choices[0].message.content` | `content[0].text` |
| 추가 헤더 | 없음 | `anthropic-version` |

Anthropic 규격 예제(콘솔):

```bash
# Anthropic 규격은 max_tokens가 필수이고, anthropic-version 헤더를 함께 보낸다.
curl https://copa.codyssey.kr/v1/messages \
  -H "x-api-key: <virtual-key>" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"claude-sonnet-4","max_tokens":1024,"messages":[{"role":"user","content":"안녕하세요"}]}'

# 응답은 choices가 아니라 content 블록 배열이다.
# { "content": [ { "type": "text", "text": "..." } ], "usage": { ... } }
```

```javascript
const response = await fetch("https://copa.codyssey.kr/v1/messages", {
  method: "POST",
  headers: {
    "x-api-key": "<virtual-key>",
    "anthropic-version": "2023-06-01",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "claude-sonnet-4",
    max_tokens: 1024,          // Anthropic 규격에서는 필수다
    // 시스템 프롬프트는 messages가 아니라 최상위 system 필드에 넣는다.
    system: "당신은 친절한 학습 도우미입니다.",
    messages: [{ role: "user", content: "안녕하세요" }]
  })
});

const data = await response.json();
// OpenAI 규격의 choices[0].message.content 와 위치가 다르다.
console.log(data.content[0].text);
```

OpenAI 호환 예제(콘솔):

```bash
curl https://copa.codyssey.kr/v1/chat/completions \
  -H "Authorization: Bearer <virtual-key>" \
  -H "content-type: application/json" \
  -d '{"model":"gpt-5-mini","messages":[{"role":"user","content":"안녕하세요"}]}'
```

### 음성 생성(TTS)

응답의 `audioUrl`은 웹 로그인 세션 전용이라 API 키로 열면 401입니다. `response_format: "b64_json"`으로 원본을 받습니다. `format`은 오디오 코덱(mp3·wav 등), `response_format`은 전달 방식입니다.[1]

```javascript
const response = await fetch("https://copa.codyssey.kr/api/v1/audio/tts", {
  method: "POST",
  headers: {
    Authorization: "Bearer <virtual-key>",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "tts-1",
    input: "안녕하세요. 코디세이입니다.",
    voice: "alloy",
    format: "mp3",               // 오디오 코덱
    response_format: "b64_json"  // 전달 방식 — 원본을 응답에 담는다
  })
});

const { result } = await response.json();
const audio = new Audio("data:audio/mpeg;base64," + result.b64_json);
await audio.play();
```

미디어 응답은 `result` 아래에 담깁니다(이미지는 `result.images[0].b64_json`, 음성은 `result.b64_json`).[2]

### 이미지·영상

- 이미지: `POST /api/v1/images`, `{ model, prompt, size, response_format: "b64_json" }`.
- 영상: 비동기. `POST /api/v1/videos` → 작업 ID → `GET /api/v1/videos/{id}`를 completed까지 반복 → `GET /api/v1/videos/{id}/download`. `resultUrl`은 웹 세션 전용이라 `downloadUrl`을 씁니다. 지원하지 않는 resolution은 400 `invalid_media_request`에 사용 가능 값이 함께 옵니다.[1]

케어브릿지는 이미지·영상을 쓰지 않아 예제 전문은 옮기지 않았습니다.

## 6. 도구 설정 (콘솔 문서 탭)

Claude Code·Cursor·Continue에 키를 붙이는 방법이 있습니다(예: `~/.claude/settings.json`의 `env`에 `ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY`). 매뉴얼은 에이전트에 상시 연결하면 토큰을 크게 쓴다고 경고합니다.[1][2]

## 7. 자주 발생하는 문제 (매뉴얼 8장)

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 응답의 url을 열면 401 | 웹 로그인 세션 전용 url | `response_format: "b64_json"`, 영상은 downloadUrl |
| 400 invalid_media_request | 지원하지 않는 resolution/size/quality | 오류 메시지의 "사용 가능=" 값으로 다시 요청 |
| 키 발급/수정이 409로 거부 | 소속 기관에 그 회사 키 미등록 | 기관 운영자에게 문의 |
| 403 "Provider credentials are unavailable" 또는 503 | 키를 발급한 기관에 그 회사 키 없음 | 발급 기관 확인 후 운영자 문의 |
| 401 invalid_api_key | 키 오타, 폐기된 키 | 키 확인, 필요하면 재발급 |
| 한도 초과 오류 | 월 차감 토큰 한도 소진 | 사용량 탭 확인, 운영자에게 한도 조정 요청 |
| max_tokens 오류 (Anthropic) | Anthropic 규격은 max_tokens 필수 | 요청에 max_tokens 추가 |

## 8. 보안 주의사항 (매뉴얼 9장)

- 키 원문을 코드 저장소, 채팅, 문서에 남기지 않습니다. 환경 변수나 시크릿 관리 도구를 씁니다.
- 유출이 의심되면 즉시 폐기하고 새로 발급합니다.
- 키는 본인 학습 용도로만 씁니다. 모든 호출은 감사 로그로 남고 운영자가 조회할 수 있습니다.
- **프롬프트·응답은 콘텐츠 이력으로 저장되어 기관 운영자가 볼 수 있습니다.**
