# 참고자료

밖에서 받은 자료와 우리가 제출한 파일을 둡니다. 우리 팀이 작성 중인 문서는 `../문서/`에 둡니다.

| 폴더 | 넣는 것 |
|---|---|
| `코디세이/` | 코디세이 안내 자료, 코디세이에 제출한 파일 |
| `공모전/` | 공모전 공고·안내, 공모전에 제출한 파일 |
| `도메인/교재지침/` | 요양보호사 교재, 정부·공단 지침과 안내서 원본 PDF와 출처. 목록은 그 폴더의 `README.md` |
| `도메인/서식/` | 기록지 등 실제 서식 (작성 예시, 교육용 양식) |
| `도메인/서식/법정/` | 법령에 실린 서식 원문(`원문/`)과 칸 구성 정리(md). 자세한 목록은 그 폴더의 `README.md` |
| `도메인/인터뷰/` | 인터뷰 질문지와 결과 |
