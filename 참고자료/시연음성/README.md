# 시연 음성

정리: 팀장 · 2026-11-07 · 이슈 #157, #315 · 합성 사례만(실명 없음)

- **목적:** 시연과 받아쓰기 확인 때 다른 기기(노트북·휴대폰 스피커)로 틀어 W2 [말로 기록]에 들려줄 음성입니다.
- **배경:** 음성 파일을 저장소 밖 공유 폴더에 두다 보니 찾기 어려웠고, 중국어(간체)·몽골어·영어 받아쓰기 확인(#315)에 쓸 음성이 없었습니다.
- **근거:** 대본 전문은 같은 폴더의 `대본.md`, 기대 결과는 `data/demo/voices.md`, 대본 원문은 `data/demo/voices.json`입니다.
- **사유:** 한 녹음에는 한 언어만 씁니다(결정 `문서/결정/2026-10-30-녹음한언어.md`). 그래서 언어마다 파일을 따로 둡니다.

| 파일 | 시나리오 | 언어 | 길이 | 일부러 남긴 '확인 필요' |
| --- | --- | --- | --- | --- |
| `voice-1-ko.mp3` | 1. 시설 (김○○) | 한국어 | 약 61초 | 식사("조금"), 엉덩이 피부 |
| `voice-2-ko.mp3` | 2. 재가·되돌리기 (이○○) | 한국어 | 약 57초 | 지원 시간 합 200분 > 방문 180분, 인지 변화 |
| `voice-3-vi.mp3` | 3. 교육용 (최○○) | 베트남어 | 약 52초 | voice-1과 같음 |
| `voice-3-zh.mp3` | 3. 교육용 (최○○) | 중국어(간체) | 약 51초 | voice-1과 같음 |
| `voice-3-mn.mp3` | 3. 교육용 (최○○) | 몽골어 | 약 57초 | voice-1과 같음 |
| `voice-3-en.mp3` | 3. 교육용 (최○○) | 영어 | 약 56초 | voice-1과 같음 |

- **이름:** `voice-[시나리오 번호]-[언어 코드].mp3`. 예전 `voice-1`·`voice-2`·`voice-3`은 각각 `voice-1-ko`·`voice-2-ko`·`voice-3-vi`입니다.
- **만든 방법:** Microsoft Edge TTS(한국어 SunHi, 베트남어 HoaiMy, 중국어 Xiaoxiao, 몽골어 Yesui, 영어 Jenny), 속도 -15%, 문장 사이 1.3초. 다시 만들려면 `python3 data/demo/make_voices.py 출력폴더 [음성 이름]`
- **확인 안 한 것:** `voice-3-zh`·`voice-3-mn`·`voice-3-en`은 받아쓰기를 아직 돌리지 않았고, 대본은 원어민 확인을 거치지 않은 번역입니다. #315에서 받아쓴 글과 대본을 맞춰 봅니다.
